# MYON v0.02 — 회사 생성과 기본 메뉴 해금

이 프로젝트는 배포 검증을 마친 **MYON v0.01 관전 사이트**에서 발전한 v0.02입니다. v0.01 관전 엔진·IndexedDB·기존 데이터·배포 설정은 그대로 유지하고, 별도 진행 상태로 회사 설립과 기본 메뉴 개방만 추가했습니다.

## 플레이 흐름

1. **처음 접속하면 관전 시작:** 5대 교통 분야(버스·철도·항공·해상·우주)의 실제 운행·운항 임무를 관전합니다. 최초에는 임무 1개가 생성되고 이후 매시간 새 임무 1개가 자동 생성됩니다. 각 임무는 0초에 도달했을 때만 폐기됩니다.
2. **회사생성 24시간:** v0.02가 배포된 후 브라우저가 이 버전을 처음 실행한 시점부터 24시간 카운트다운이 시작됩니다. 이미 v0.01에서 관전하던 브라우저도 v0.02를 처음 실행한 시점부터 카운트합니다. 회사생성 카운트는 일반 임무들과 함께 남은 시간 순으로 자동 정렬됩니다.
3. **회사생성 폼:** 24시간이 끝나면 회사생성 폼이 홈 맨 위에 고정됩니다. 유저가 직접 회사명을 입력하고 생성 확인을 하기 전에는 관전 상태를 계속 유지하며, 메뉴/표준시간/버전은 표시되지 않습니다. 회사 설립을 강요하지 않습니다.
4. **회사 생성 완료:** 탑에 `MYON | 회사명`이 표시되고 실제 한국 표준시간(KST)과 `v0.02` 정보가 표시됩니다. 기존 관전 임무는 중단되지 않습니다.
5. **기본 메뉴 해금 시작:** 홈의 임무 목록 맨 아래에 `기본 메뉴 해금` 카드가 나타납니다. **유저가 직접 '시작'을 눌러야** 1시간 카운트다운이 시작됩니다. 그 전에는 카운트가 흐르지 않습니다.
6. **기본 메뉴 개방:** 시작 후 정확히 1시간이 지나면 메뉴 카드가 홈 최상단(탑 메뉴 바로 아래)에 영구 고정됩니다. 메뉴 카드 클릭 시 별도의 메뉴 화면으로 이동합니다.
7. **기본 메뉴 내용:** `회사 관리`, `설정` 카드 두 개만 있고 둘 다 `Coming soon`으로 잠겨 있습니다. 다른 운영 시스템을 아직 개방하지 않습니다.
8. **하단 이동바:** 메뉴 화면에서 하단에는 항상 `← 이전메뉴 | 현 메뉴명 | 홈`이 고정되어 있습니다. 홈은 바로 관전 임무 화면으로 돌아가고, 홈의 기본 메뉴 카드를 눌러 다시 들어갈 수 있습니다.

## 중요한 규칙

- **배포된 앱의 버전과 유저 개인의 진행 단계는 다릅니다.** v0.02가 배포되었다고 모든 유저에게 회사가 자동으로 생기지 않습니다.
- 회사 생성은 선택입니다. 회사 생성 폼이 등장한 후에도 영원히 관전만 계속할 수 있습니다.
- 회사 생성 완료 후에도 v0.01 운행·운항 임무 생성/완료/폐기는 기존과 같은 방식으로 계속 진행됩니다. 후속 버전에서 임무 생성 방식은 별도로 변경할 수 있습니다.
- 24시간 회사생성 및 1시간 기본 메뉴 해금은 **실제 경과 시간**을 기준으로 하므로 탭을 닫았다 재접속해도 처음부터 다시 시작하지 않습니다.
- 회사명과 메뉴 해금 상태는 별도의 IndexedDB (`myon-progression-v002`)에 기록됩니다. 관전 기록은 기존 IndexedDB (`myon-observation-preview-v1`)를 유지합니다.
- 현재 v0.02는 브라우저별 로컬 저장 방식입니다. 기기 간 동기화 및 save.json 내보내기·불러오기는 이번 버전에 포함하지 않습니다.

## 파일 구성

- `src/ObservationView.vue` — v0.01 관전 화면 확장 및 v0.02 단계별 UI
- `src/progression.js` — 회사/메뉴 해금 상태, 각 타이머, IndexedDB 저장
- `src/observation.js` — v0.01 교통 임무 엔진 **변경 없음**
- `src/App.vue` — 관전/운영 공통 진입 화면 (기존 구조 유지)
- `src/LegacyApp.vue`, `src/gameEngine.js`, `src/storage.js`, `src/style.css` — 기존 프로젝트 파일 그대로 보존

## 실행 및 배포

```bash
npm ci
npm run build
```

GitHub Pages는 기존과 동일하게 Vite `base: '/MYON/'`을 사용합니다. ZIP에는 `tests/` 폴더, 별도 테스트 파일, 독립 미리보기 HTML을 포함하지 않습니다.
