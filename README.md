# MYON v0.01 — 교통운영 관전 사이트

최신 간소화 적용본을 기반으로 완성한 **v0.01 관전 시스템**입니다.

## 최초 게임 화면
- 회사 설립 기능은 아직 구현하지 않았습니다. 따라서 유저는 카운트다운 관전만 할 수 있습니다.
- **임무 목록의 맨 마지막에 비활성 안내 행 `회사생성` / `Coming soon`을 표시합니다.** 클릭이나 실행 동작은 없고 실제 회사 설립 기능은 추후 버전에서 구현합니다.
- 상단에는 `MYON` 로고만 표시합니다. 메뉴, 실제 표준시간, 버전, 비서, 진행 안내는 표시하지 않습니다.
- 모바일 및 PC 모두 가로폭 100%의 1열 카드로 표시합니다.
- 카드에는 **[버스/철도/항공/해상/우주] [운행·운항 임무명] [남은 시간]**만 표시합니다.
- 남은 시간이 가장 짧은 카드가 위에 오며, 세로 스크롤은 가능하지만 스크롤바는 보이지 않습니다.

## 생성·완료 규칙
- 관전 **최초 시작 시 임무 1개**를 생성합니다. 이후 **관전 시작 시각을 기준으로 정확히 1시간마다 신규 임무 1개**를 추가합니다.
- 기존 임무가 몇 개이든 매시간 생성합니다. 완료 시 대체 생성하지 않습니다.
- 임무마다 독립된 카운트다운(현실 1초 = 1틱)을 진행합니다.
- 임무의 남은 시간이 **0초가 되어야만** 폐기합니다. 새 임무가 생성되더라도 이미 진행 중인 임무는 유지합니다.
- 교통 분야 5개는 동일 확률로 무작위 선정합니다. 해당 분야의 운행 방식 및 소요 시간을 독립적으로 무작위 선정합니다.

| 구분 | 임무명 기준 | 소요 시간 |
|---|---|---|
| 버스 | 0~9999 노선번호(1~4자리) + 노선 운행 | 30분~4시간 |
| 철도 | 지하철 / 일반열차 / 고속열차 운행 | 2~6시간 |
| 항공 | 국내선 / 국제선 항공편 운항 | 2~15시간 |
| 해상 | 국내선 / 국제선 선박, 관광선, 해상버스 운항 | 2시간~1달 |
| 우주 | 항성 간 이동, 우주셔틀, 행성 간 수송, 궤도 수송 | 1~4달 |

> 랜덤 시간 범위에서 **1달은 30일**, 4달은 120일로 계산합니다. 랜덤 시간은 1분 단위로 부여합니다.

## 저장 및 재접속
- 관전 상태는 기존 IndexedDB에 자동 저장합니다.
- 각 임무는 실제 종료 시각을 기록하므로 탭을 닫거나 브라우저가 백그라운드에 있어도 시간은 계속 흐르는 것으로 계산합니다.
- 다시 접속하면 빠뜨린 시간 슬롯의 임무를 계산해 **완료한 것은 복원하지 않고 현재 진행 중인 것만** 표시합니다.
- 4달보다 오래된 임무는 진행 중일 수 없으므로 아주 오랜 미접속 후에도 과거 모든 임무를 메모리에 누적하지 않습니다.
- 기존 v0.01 관전 체험 데이터가 있다면 **진행 중인 타이머와 임무 ID를 유지**하고, 새 교통 운행 임무명으로만 전환합니다. 완료된 체험 임무는 제거됩니다.
- 별도 서버는 필요하지 않습니다. 오프라인 경과 시간을 실제로 서버가 실행한 것처럼 **재접속 시 계산하여 복원**합니다.
