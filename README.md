# MYON v0.01 — 도시 임무와 기본 해금 시스템

**게임 버전은 0.01 그대로 유지**합니다. Vue 3 + Vite, GitHub Pages `/MYON/` 경로, 기존 철도 운행·차량·노선·저장 기능을 유지하며 도시 임무 시스템을 추가했습니다.

## 처음 시작하는 화면

- **도시 임무 10개**가 진행 중 상태로 표시됩니다. 도시는 서울·부산·인천·수원·대전·대구·광주·울산·세종·제주를 대상으로 하고, 제목은 기본 10가지 도시 업무에서 자동 선정됩니다.
- 각 도시 임무의 소요 시간은 내부적으로 **15분~4시간(5분 간격)**으로 정해집니다. 완료 시 새 임무가 배정되어 슬롯 10개가 계속 유지됩니다. 임무 소요 시간 범위는 초기 구현값으로, 나중에 조정할 수 있습니다.
- **회사 신설·시간 연구·자금 연구·비서 연구**가 함께 표시되며 각자 독립적으로 시작할 수 있습니다. 각각 실제 24시간이 경과하면 자동 완료됩니다. 해금한 연구 카드는 목록에 남아 완료 상태로 표시됩니다.
- 회사·자금·표준시간은 시작 화면에 표시되지 않습니다. 시간 해금 전에는 임무/연구의 소요 시간, 남은 시간, 완료 예정 시각과 표준시간도 숨겨집니다.
- 도시 임무는 연구에 관계없이 항상 자동 진행됩니다. 기록은 순환 과정에서 폐기되며 도시 임무 완료 목록은 만들지 않습니다.

## 해금별 작동 방식

| 기본 연구 | 해금 후 기능 |
|---|---|
| 회사 신설하기 | 회사 메뉴와 **기존 철도 운행·차량·노선·심층 연구** 메뉴가 표시됩니다. 회사 이름은 임시 기본값 ‘나의 회사’이며 세부 경영은 후속 개발 대상입니다. |
| 시간 연구하기 | 상단 현재 표준시간, 도시 임무/철도 운행/기본 연구의 남은 시간·완료 시각 등이 표시됩니다. |
| 자금 연구하기 | 상단 보유 자금 **0 M**부터 시작합니다. 해금 시각 **이후 완료되는** 도시 임무부터 보상을 정산합니다. |
| 비서 연구하기 | 비서 메뉴에서 버전과 무관한 **날짜별 시스템 변경기록**을 확인할 수 있습니다. 추가 안내·위키는 향후 회사 연구로 확장합니다. |

**M 자금 규칙**: 도시 임무의 수락 기준은 50 M/초, 완료 보상은 100 M/초입니다. 초기 자본 0 M에서도 자동 임무가 끊기지 않도록 완료 시 **보상에서 수락비용을 공제하여 순수익 50 M/초를 지급**합니다. 수락 시에 선불로 차감하지 않습니다. 자금 해금 이전 완료분에는 소급 지급하지 않습니다.

**시간 규칙**: 현실 1초 = 1틱, 시간 기준은 내부적으로 언제나 존재합니다. 브라우저가 종료되면 실제 실행은 중단되지만, 재접속 시 저장된 시각과 현재 시각을 이용해 도시 임무·연구·철도 운행을 복원합니다. 시각 표시는 이용자 브라우저의 현지 표준 시각을 사용합니다.

## 기존 기능 보호 및 데이터 호환

- 회사 해금 이후 기존 `기관차 L-001`, `객차 C-001/C-002`, 기본 철도 노선, 운행·위치 추적, 노선 연구와 개인 경로 생성/삭제를 계속 이용합니다.
- 기존의 1회 운행 완료 조건 `노선 설계` 연구는 회사 심층 연구에 유지합니다. 기존 `시간 관측` 연구가 완료된 **구 v0.01 저장 데이터**에는 시간 해금 권한을 그대로 인정합니다. 신규 플레이어는 `시간 연구하기` 24시간으로 해금합니다.
- **기존 `save.json` 및 IndexedDB 스냅샷**에서 도시 임무와 해금 상태가 없는 경우 시작 데이터를 보완합니다. 개인 노선·기관차·객차·운행·연구·진행 기록을 삭제하지 않습니다. 마이그레이션 전에 완료한 도시 임무로 보상을 소급 생성하지 않습니다.
- 이전 v0.01에서 **이미 철도 운행·노선 연구·개인 경로 진행 기록이 있는 사용자**는 과거에 이용하던 철도 기능이 24시간 잠기지 않도록 회사 접근 권한을 이관합니다. 아무 운행도 하지 않은 옛 기본 저장 데이터에는 회사가 자동 해금되지 않습니다. 신규 플레이어는 반드시 회사 연구(24시간)를 진행합니다.
- `save.json` 한 파일로 모든 상태를 내보내기·불러오기 할 수 있습니다. 진행 중인 도시 임무 10개, 4가지 연구 시작 시각 및 진행 상태도 포함합니다.
- 고정배차 전 완료 운행의 상세 기록은 저장하지 않습니다. 고정배차, 편성 연결/분리, 복합열차, 폐색, 리얼 경제, 항공 ATC는 **아직 미구현**입니다.

## 로컬 실행 및 GitHub Pages 배포

```bash
npm ci
npm test
npm run build
```

- GitHub 저장소: `MYON-World/MYON`. Vite의 `base: '/MYON/'` 설정을 바꾸지 않았습니다.
- ZIP에는 **`.github` 폴더를 포함하지 않습니다.** 기존 저장소의 GitHub Actions 설정은 그대로 둡니다.
- 사이트에 자동으로 업로드되는 ZIP이 아닙니다. 배포 전 기존 소스와 개인 `save.json`을 백업한 뒤 GitHub 저장소에 반영하세요.
- IndexedDB와 localStorage의 기존 저장 키(`myon-game-v001`, `myon-game-v001-cache`)를 유지합니다. 기존 파일을 명시적으로 삭제하지 않습니다.
