# MYON v0.03 — 자금 엔진

배포 확인된 MYON v0.02 프로젝트를 바탕으로 만든 엔진 확장 버전입니다. 회사 생성·기본 메뉴 해금·관전 임무 생성/폐기·기존 저장 데이터를 그대로 유지합니다.

## 처음 접속부터 자금 엔진 이용까지

1. **기존 관전/회사 설립:** 회사생성 24시간 → 직접 회사 설립 → 기본 메뉴 해금 임무 직접 시작(1시간)은 v0.02와 동일합니다.
2. **기본 메뉴 해금 후:** 홈 임무 리스트 마지막에 `자금 엔진 해금`이 등장합니다. 클릭해서 시작하면 1시간 카운트다운이 진행됩니다. 타이머는 일반 운행·운항 임무와 함께 남은 시간 순으로 정렬됩니다.
3. **메뉴별 해금:** 기본 메뉴의 `회사 관리`, `설정`은 각각 클릭해 1시간 해금을 시작합니다. 각 메뉴는 해금 완료 후 클릭하면 진입할 수 있습니다. 메뉴 화면 하단 `← 이전메뉴 | 현 메뉴명 | 홈`은 기존대로 유지합니다.
4. **회사 관리:** 자금 엔진을 해금했다면 현재 보유 자금(M), 진행 중인 운행·운항 임무 수, 초당 수익을 표시합니다.
5. **설정:** 자금 엔진을 해금했다면 자금 엔진의 ON/OFF를 직접 선택할 수 있습니다. 초기값은 **OFF**이며, 켤 때부터 수익이 발생합니다.

## 자금 엔진 규칙

- **엔진 해금:** 1시간. 해금과 ON/OFF는 서로 다른 상태입니다.
- **ON:** 현재 진행 중인 임무 1개당 현실 **1초에 1M** 자동 적립. 예: 5개 진행 중이면 초당 5M.
- **OFF:** 자금 수익이 없지만 관전 임무의 생성·진행·완료는 정상 작동합니다.
- **ON → OFF → ON:** 다시 켰을 때 자금은 **0M부터** 시작합니다. OFF 동안 누적 수익이 발생하지 않습니다.
- **미접속 기간:** IndexedDB에 정산 시점을 저장하고, 접속하지 않았던 동안 진행되어 완료된 운행·운항 임무까지 원래 생성 슬롯/시작/종료 시각을 기준으로 정산합니다. 브라우저를 열어둘 필요가 없습니다.
- **안전성:** 여러 탭에서 중복 정산되지 않도록 IndexedDB의 readwrite 트랜잭션 안에서 기존 정산 시점을 읽어 누적합니다.
- **비경제 모드:** 엔진 OFF에서도 향후 기능/엔진 해금을 시간으로 진행할 수 있습니다. 경제 모드에서 필요한 후속 엔진/업그레이드 비용은 그 기능을 실제로 추가할 때 결정합니다. 이번 버전에서 임의의 가격을 만들거나 비용을 청구하지 않습니다.
- **RPG 엔진 연계 업그레이드:** RPG 엔진이 아직 없으므로 자금 엔진의 성장/업그레이드 UI는 이번 버전에 포함하지 않습니다.

## 파일과 저장

- `src/financeEngine.js` — 자금 엔진 해금·시간별 누적 정산·재활성화·IndexedDB 트랜잭션
- `src/ObservationView.vue` — 자금 엔진 해금 카드, 회사 관리 자금 표시, 설정 ON/OFF, 메뉴별 1시간 해금
- `src/observation.js` — **기존 v0.01 관전 엔진 변경 없음**
- `src/progression.js` — **기존 v0.02 회사 생성·기본 메뉴 진행 저장 변경 없음**
- 기타 파일 및 Vite `base: '/MYON/'` 설정 그대로 유지

기존 관전 저장소 `myon-observation-preview-v1`과 진행 저장소 `myon-progression-v002`를 변경하지 않습니다. 자금과 메뉴별 해금은 신규 IndexedDB `myon-finance-engine-v1`에 별도로 저장합니다.

## 실행 및 배포

```bash
npm ci
npm run build
```

원본과 동일하게 GitHub Pages의 `/MYON/` 경로로 배포할 수 있습니다. ZIP에는 `node_modules`, `dist`, `tests`, 별도 테스트 파일을 포함하지 않습니다.
