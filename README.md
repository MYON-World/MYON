# MYON v0.01 — 도시 임무 기본판

도시 이름을 정하고 회사명을 등록하면 도시에서 발생하는 임무를 수락해 회사를 운영합니다.

## 시작

```bash
npm ci
npm run dev
```

배포는 기존 Vite/Vue 프로젝트처럼 `npm run build`로 `dist/`를 생성합니다. GitHub Pages 배포 설정은 `vite.config.js`에 있습니다.

## v0.01의 기능

- 도시 및 범용회사 이름 지정 (회사명 등록 전 임무 이용 차단)
- 분야별 메뉴가 없는 통합 도시 임무 목록 (사전에 정해진 다양한 이름)
- 수락 기한이 만료되면 임무 자동 폐기 및 새 임무 등장
- 초기 동시 수락 최대 2개, 수행 완료 시 자리 반환
- 임무 수락 시 회사 부담 비용 선지출; 시 분담금은 시가 부담
- 완료 시 회사 부담 원금 반환 + 순이익 회사 몫(초기 순이익의 10%) 정산
- 0 M에서도 시작 가능한 시 전액 부담 소규모 임무 제공
- 실시간 남은 시간 및 진행바, 오프라인 복귀 시 경과 시간 계산
- IndexedDB 자동 저장, 로컬 예비 저장, save.json 내보내기·불러오기
- 같은 v0.01의 직전 택시 버전 백업은 새 임무 형식으로 안전하게 이전합니다. 옛 운행 데이터는 `legacyTransport` 안에 보존하지만 운행은 중단됩니다.

## 계산

`임무 순이익 = 최종 보상액 - (시 분담금 + 회사 부담금)`

`회사 순수익 = floor(임무 순이익 × 10%)`

수락 즉시 회사 부담금을 차감하고, 완료 시 그 부담금을 반환하며 회사 순수익을 추가합니다. 따라서 한 건의 회사 자금 순증가액은 **회사 순수익**과 같습니다. 비율 조절이나 연구는 아직 구현하지 않았습니다.

## 이번 버전의 범위

초기 임무 수락·완료·정산만 구현했습니다. 연구 해금, 임무로 열리는 사업/시설, 시와 회사 분담 비율 조절, ATC 등은 후속 버전의 확장 범위입니다. 기존의 철도/ATC 실험 소스는 별도 파일에 남겨 두었지만 앱의 메뉴에서는 실행하지 않습니다.

## 데이터 유의사항

브라우저는 기존 MYON v0.01 IndexedDB 네임스페이스를 사용합니다. ZIP 교체 시 기존 백업을 먼저 내보내는 것을 권장합니다. 다른 버전의 저장 파일을 불러올 때에는 먼저 스키마를 검증합니다.
