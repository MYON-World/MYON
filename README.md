# MYON 변경 기록

- 2026.10.27 / **0.08.13** / 상단 분야 구분 태그 8개와 필터 기능 삭제. 도시 32종·교통 30종을 항상 전체 목록에 통합 표시하고 임무 카드의 `[분야]` 접두어 유지. 기존 미수락 폐기 임박순·수락 임무 완료 임박순 정렬, 저장·자동수락·연구·10개 카드 제한 유지. 0.08.05 상단/기본 카드/하단 레이아웃 복구.

- 2026.10.27 / **0.08.12** / 교통 운행 분야 6개(택시·버스·철도·항공·선박·우주) 각 5종 총 30개 일반 임무 추가, 기존 도시 32종 포함 전체 62종. 전체/도시/6개 분야 태그 카드 필터와 `[분야]` 임무 제목 추가. 필터 전환과 관계없이 임무 진행·자동수락·만료·10개 카드·저장·오프라인 진행은 유지. 기존 MYON 시계·하단 메뉴·원래 카드 스타일은 고정.

- 2026.10.27 / **0.08.11** / 시간 업그레이드 비율에 따라 새 임무 등장 간격(초기 4~8.5초→최종 40~85초)과 미수락 폐기시간(초기 17~33초→최종 15~30분) 단계별 확대. 이미 등장한 임무 시간 보존, 연구 완료 시 다음 등장 예약 갱신, 이전 저장자료 유지. 0.08.05 고정 레이아웃 변경 없음.

- 2026.10.27 / **0.08.10 긴급 수정** / 자동수락에서 임무시간 업그레이드 1~10 및 자동수락 해금 임무 제외를 후보 선택과 시작 단계 모두에서 이중 방어. 일반 도시 임무 32종만 자동 수락 가능. 직접 연구 시작, 저장·오프라인 진행 및 고정 레이아웃 유지.

- 2026.10.27 / **0.08.09** / 일반 임무시간을 현실 10%에서 100%까지 순차 증가시키는 임무시간 업그레이드 10회 추가(5분~24시간 연구, 한 번에 한 단계). 기존 임무 카드에서 수동 시작, 오프라인 진행/단계 저장, 자동 수락 연구 제외. 32종 현실/10%/100% 임무표를 `docs/MISSIONS.md`에 정리. 기존 플레이 기록과 0.08.05 레이아웃 유지.

- 2026.10.26 / **0.08.08** / 일반 임무 32종을 현실 작업시간 추정치의 10%로 체계화(6/12/24/36/48/72분). 자동 수락 해금 24시간은 유지. 기존 진행 임무 완료시각·저장자료·오프라인 계산·0.08.06 자동수락 기능·전체 카드 10개 상한과 v0.08.05 레이아웃 유지.

- 2026.10.26 / **0.08.07 긴급 수정** / 화면 HTML·CSS를 0.08.05 원본 그대로 유지(버전 문자열만 갱신). 0.08.06의 DOM 재삽입 정렬을 CSS order 방식으로 교체해 스크롤 점프 방지. 자동수락 해금·정렬·전체 10개 제한 및 v0.08.06 저장자료 유지.

- 2026.10.26 / **0.08.06** / 24시간 진행 후 영구 해금되는 자동 임무 수락 카드 추가. 해금 후 첫 1분 쿨타임, 10분에 1건 자동 수락(폐기 임박 임무 우선), 수락 후 1분 쿨타임. 미수락/수락 시간순 정렬. 업그레이드 포함 전체 카드 최대 10개, 9개 이하일 때만 등장. 기존 0.08.05 저장자료 이관·오프라인 진행 유지.

- 2026.10.26 / **0.08.05** / 기본 KST 디지털 시계 확대(상단 날짜 + 큰 HH:MM, 1초 틱), 처음부터 IndexedDB 자동저장 및 실제 오프라인 경과시간 계산. 시간·저장 연구 제거. 임무 시간/카드/한도 유지. 하단 홈·메뉴 1·메뉴 2·설정 4개 구성. v0.08.04 전체 저장 임무는 데이터 삭제 없이 새 키로 이관.

- 2026.10.25 / **0.08.04** / 안정적인 신규 시작 기준: 이전 0.08.03 진행 저장은 초기화하고 새 IndexedDB로 분리. 임시 저장·시간 연구는 무작위로 등장하며 직접 시작해야 함. 0.08.04에서 새로 획득한 진행 저장은 이후 유지. 오프라인 진행 미해금·통합 10건 제한은 그대로.

- 2026.10.25 / **0.08.03 (수정 커밋)** / 저장은 유지하되 브라우저 종료·숨김 중 오프라인 진행 제거. 임무·연구·폐기·등장 타이머는 재접속 시 남은 시간부터 재개. 임무와 연구의 동시 진행 한도를 통합 10건으로 변경.
- 2026.10.25 / **0.08.03** / 무작위 등장 임시 저장 연구(1시간): 시작 시 연구 기록만 IndexedDB에 보존, 완료 시 전체 게임 자동저장·재접속 복원 해금. 설정 개방 후 내보내기·불러오기 예정.

- 2026.10.25 / **0.08.02** / 24시간 시간 연구 무작위 등장, 연구 전 시간 정보 숨김, 연구 후 상단 KST 시계와 미수락 임무 폐기시간·진행 중 완료까지 남은 시간의 한 줄 카운트. 기존 임무/화면 및 저장 없음 유지.

- 2026.10.25 / **0.08.01** / 구버전 UI·전용 코드·진입 경로 제거, 신규 통합 도시 임무 게임을 기본/유일한 화면으로 전환. 각 임무 별도 카드·무작위 등장 및 소멸·동시 10건 비표시 제한·수동 시작·회사와 설정 잠금·스크롤바 숨김·시계/자금 비표시·저장 기능 없음.
