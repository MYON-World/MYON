# MYON v0.01 — 도시 중심 재구성

기존 **철도 운행 중심** 화면과 중복 메뉴를 제거하고, 유저가 자유롭게 해금하며 확장하는 MYON의 기본 세계를 다시 구성했습니다. 화면, 게임 엔진, CSS를 새로 작성했고 **게임 버전은 0.01 그대로**입니다.

## 시작 화면

- **도시 임무 10개**가 자동으로 진행·완료·교체됩니다. 초기에는 10가지 주제가 각각 한 번씩 노출되며, 교체 시 도시와 주제가 랜덤 조합됩니다.
- **기본 연구 4개**(회사/시간/자금/비서)를 원하는 순서대로 독립적으로 시작할 수 있습니다. 각 연구는 현실 시간 24시간 경과 시 자동 해금됩니다. 완료 연구 카드도 남기 때문에 총 14개 슬롯이 유지됩니다.
- **시간 연구 전:** 현재 표준시간, 남은 시간, 소요 시간, 완료 시각 등이 보이지 않습니다. 내부 시간은 언제나 **1틱 = 실제 1초**로 흐릅니다.
- **자금 연구 전:** 잔액도 완료 수익도 없습니다. 해금 순간 **0 M**이 되며, 그 시각보다 **늦게 완료된** 도시 임무부터 정산됩니다.
- 도시 임무 **수락 기준 50 M/초, 완료 보상 100 M/초**이며, 자동 순환과 초기 0 M을 고려해 완료 시 비용을 공제하고 **순수익 50 M/초**가 적립됩니다. 임무 시작 시 선불 차감하지 않습니다.
- **회사 연구 전:** 회사 화면/메뉴는 숨겨집니다. 연구 후 회사 이름과 심층 연구의 공간이 열리지만 추가 심층 콘텐츠는 아직 개발 전입니다.
- **비서 연구 전:** 비서 화면/메뉴는 숨겨집니다. 최초 해금된 비서는 변경기록과 회사 연구 안내만 제공합니다.

## 철도 관련 기존 구성 정리

이 ZIP에서 기존 기본 기관차, 객차, 철도 운행 및 개인 노선 UI/엔진을 **제거했습니다.** 해당 기능들이 현재 이용 가능한 것처럼 표시되지 않습니다. 추후 회사의 연구로 철도 분야를 단계적으로 새로 추가할 예정이며, 과거 자료를 새 기본 화면에 억지로 결합하지 않습니다.

## 저장 데이터 보호와 새 출발

- 새 IndexedDB 저장공간 이름은 `myon-world-core-v001`, 보조 localStorage 키는 `myon-world-core-v001-cache`입니다. **이전 버전의 `myon-game-v001` 데이터베이스 및 `myon-game-v001-cache` 값은 수정·삭제하지 않습니다.** 따라서 동일 브라우저에서도 새 진행으로 시작합니다.
- 통합 파일은 항상 **`save.json`** 하나입니다. 파일을 직접 불러온 경우에만 현재 데이터가 교체됩니다(확인 창 제공).
- 이전 철도형 `schemaVersion:1` save.json을 직접 가져오면, 연구 해금/잔액은 가능한 범위에서 이관하고 철도 노선·차량·운행·이력은 `legacyArchive`에 **보관만** 합니다. 철도 메뉴가 재등장하거나 구 운행을 실행하지 않습니다.
- 현재 데이터는 `schemaVersion:2`이며 **표시 버전과 별개**입니다. 게임 버전은 계속 **v0.01**입니다.
- 브라우저 종료 후 재접속 시 진행 중인 임무와 24시간 연구의 경과 시간을 계산합니다. 종료 상태에서 JavaScript가 실제 실행되는 것은 아닙니다.

## GitHub Pages

- 프로젝트: `MYON-World/MYON`
- Vue 3 + Vite 배포 경로: **`/MYON/`** (설정 유지)
- `.github` 폴더는 ZIP에 포함하지 않습니다. 기존 저장소의 `.github/workflows` 파일을 **삭제하지 말고 유지**해 주세요.
- 배포 전 기존 GitHub 프로젝트와 현재 save.json을 별도로 백업하는 것을 권장합니다. 신규 ZIP 압축 해제 파일로 기존 프로젝트의 소스/스타일을 교체하되 `.github` 폴더를 보존해야 합니다.

```bash
npm ci
npm test
npm run build
```

## 이후 확장

회사 연구에 따라 교통·차량·노선·편성·고정배차·폐색, 비서 위키, 리얼 경제(사용자 확인 후 영구 전환), 장기 항공 ATC 등을 단계적으로 추가합니다. 현재 단계에서 실제 구현하지 않은 기능을 열어놓지 않았습니다.
