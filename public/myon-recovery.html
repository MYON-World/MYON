복구 전 주의사항

반드시 이전에 MYON을 플레이하던 같은 기기·같은 브라우저·같은 프로필에서 여세요. 시크릿 모드에서는 기존 저장소가 보이지 않을 수 있습니다.
캐시 전체 삭제, 사이트 데이터 초기화, 브라우저 재설치를 하지 마세요.

원본 자료 보관 안내

JSON 파일은 현재 브라우저에 남아 있는 게임 기록을 백업합니다. 개인정보가 일부 포함될 수 있으니 공개 게시판이나 GitHub 저장소에는 올리지 마세요. 복구 작업 전까지 파일을 보관하는 것이 안전합니다.

세이브가 모두 사라졌다면 이 페이지로 이전 데이터를 만들어낼 수는 없습니다. 다른 브라우저·기기에서 사용했는지, 이전에 백업 파일을 저장했는지도 확인해야 합니다.
