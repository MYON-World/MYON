# MYON 게임 설계 기준

> 2026-10-25 / v0.08.04
> [확정] 사용자 요구사항 · [현재 구현] GitHub main · [미정] 후속 결정

## 핵심 방향 [확정]
- MYON은 교통 전용이 아닌 다양한 도시 사건을 다루는 방치형+시뮬레이션 게임.
- 도시는 원래 불안정하다. 그 세계관을 상태 배너나 장황한 설명으로 보여주지 않는다.
- 초반에는 플레이어가 직접 임무를 시작하고, 성장한 뒤 점진적으로 자동화를 얻는다.
- 성장할수록 현실적인 시스템이 깊어져 어려워진다. 자동화로 느리게 운영할 수도 있고 직접 개입할 수도 있어야 한다.

## 초기 화면 [확정/현재 구현]
- 상단에 MYON만 표시. 시간 연구를 완료하면 우측에 KST `yyyy.mm.dd HH:MM` 디지털 시계를 1초마다 갱신한다.
- 홈에는 분야 구분 없이 하나의 임무 목록; 각 임무가 별도 카드. 제목과 '시작' 버튼만 표시.
- 시간 연구 전에는 완료·폐기 시간과 진행률을 표시하지 않는다. 시작하면 `임무 진행중`만 보인다. 연구 후에는 한 줄 카드: 미시작 `임무명 / 폐기 MM:SS / 시작`, 진행 중 `임무명 / HH:MM:SS`. 기존 진행 중인 카드에도 즉시 적용한다.
- 임무 목록 제목과 건수, 자금, 도시 불안정 표시, 운영 단계, 수동/자동 상태 설명 없음.
- 세로 스크롤 허용, 스크롤바 숨김.
- 하단 메뉴는 홈/회사/설정. 회사·설정 초기 잠금.

## 임무 동작 [확정/현재 구현]
- 여러 분야의 도시 사건이 무작위 시점에 계속 등장.
- 미수락 임무는 기한 후 사라지며, 도시의 다른 주체가 해결한 것으로 취급.
- 일반 임무와 모든 연구를 합쳐 **동시 진행 최대 10건**. 숨겨진 제한으로, 임무든 연구든 11번째 시작 시 짧게 불가 안내.
- 시작한 임무는 시간 경과 후 완료되어 목록에서 사라짐. 완료 시간을 화면에는 표시하지 않음.
- 내부 임시 밸런스(향후 확정 필요): 최초 3건, 추가 등장 4~8.5초 간격, 미수락 폐기 17~33초 후, 진행 완료 2~6분 후. 모두 비노출.
- 시간 연구는 무작위 등장한다. 미수락이면 폐기되고 다시 등장할 수 있다. 시작 시 소요 시간/진행률을 숨기며, **게임 실행 중 누적 24시간** 후 시계가 해금된다. 다른 임무·연구와 합산 10건에 포함된다.
- `임시 저장 연구`가 무작위 등장하며 미수락 시 사라지고 재등장할 수 있다. 연구 시작 시 **게임 실행 중 누적 1시간** 동안 연구 중이라고만 표시한다. 일반 임무·시간 연구와 슬롯을 공유한다.
- 첫 저장 연구 시작 순간 해당 연구 진행 시각만 IndexedDB에 기록하고, 이 연구만 재접속 이후 **종료 당시 남은 시간부터** 이어진다. 연구 완료 전에는 임무·시간 연구는 아직 저장하지 않는다.
- 저장 연구가 완료된 순간부터 임무·연구·해금 상태 등 전체 자동저장이 작동한다. 종료하거나 백그라운드에 있는 시간은 **모든 게임 타이머에서 제외**하고, 재접속 후 저장된 남은 시간부터 진행한다. 저장(상태 보존)과 오프라인 진행(미해금)을 구분한다. 시간 연구의 표준시계는 실제 KST 표시를 계속한다.

## 미정
