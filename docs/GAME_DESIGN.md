# MYON 게임 설계 기준

> 2026-10-24 / GitHub main 기준 **v0.07.01**
> **[확정]** 관리자 결정 / **[구현]** 현재 코드 / **[미정]** 후속 설계

## 게임 및 화면 [확정/구현]
- MYON 자체가 회사이며 별도 회사 생성 절차가 없다. 모든 분야는 공용 자금 **M**을 공유한다.
- 기본 진입은 항상 **홈**. 하단 메뉴는 **홈 / 운영 / 설정** 3개다.
- **홈**: 자금만 표시(공용 자금이라는 문구 없음), 실제 사업을 시작한 후 **운영 현황**에 각 차량의 실시간 미터기 표시.
- **운영**: 메신저와 선택된 사업. 현재 선택 가능한 사업은 **택시**뿐이며, 추가 사업 선택 목록은 향후 회사 성장 기능 설계 전까지 숨긴다.
- **설정**: 알림 표시 설정.
- **메신저**: 시작 시 자동으로 화면을 가리지 않으며, 최초 도움 요청을 운영 탭 알림 및 홈의 '새 메세지가 도착했어요'로 1회 안내한다. 열어서 확인하면 읽음 처리하고 다음 방문부터 알림을 반복하지 않는다.
- 신규 사용자는 메신저의 **'도와드릴게요.'** 답변 버튼을 누르면 자신의 말풍선이 즉시 보이고, 지원팀 입력 중 연출을 거쳐 **'감사합니다. 선택가능한 분야를 선택해주세요.'** 답장을 받는다. 대화는 완료 상태로 저장되며 이후에도 운영 → 메신저에서 다시 확인할 수 있다.
- 메시지 마지막에 택시 선택지가 표시되고, 선택하면 운영에 택시가 추가된다. 신규 사용자는 **'첫차 지원받기'** 버튼으로 시 지원율 90%의 첫 차량을 1회 받는다.
- 신규 사용자의 초기 공용 자금 **0 M**. 초기 관찰 가능 수는 **1대**를 기준으로 후속 연구 구조를 설계한다.
- 택시 미터기: 차량 번호, 자동운행 문구, 시 지원 상환액을 노출하지 않는다. **남은 거리 / 남은 시간 / 현재 요금 / 얇은 진행바**만 표시하며 홈과 택시 화면은 동일한 운행 상태를 보여준다.
- 상환 및 시 지원금 내역은 향후 별도 회사 기능에서 다룰 예정. 현재 새 UI에서는 직접 상환 기능을 제공하지 않지만 기존 상환 잔액 및 자동 공제는 계속 유효하다.

## 운행/요금 규칙 [기존 구현 유지]
- 보유 택시 최대 **20대**, 시 지원금 완납 여부와 관계없이 모든 차량은 자동 운행한다.
- 거리 1~10km, 0.1km 단위 무작위, **1km당 3분**. 운행 종료 후 자동 정산 및 다음 운행 시작.
- 기본요금 **4,800 M**, 기본거리 **1.6km**, 초과 **131m당 100 M**. 주행 중 현재 거리 기준 미터기 요금 실시간 반영.
- 운행 중 교통정체·추가시간 변수 없음. 재접속 시 각 차량 최대 5,000회씩 완료 운행 정산 처리.
- 차량가격 **30,000,000 M**. 최초 차량은 별도 결제 없이 지급하되 시 지원금 미상환액 **27,000,000 M**, 납부율 **90%**로 시작.
- 추가 차량의 지원율 0~90%·자기부담금 및 상환 계산식은 과거 데이터와 코드 규칙을 보존하되 **새 UI의 추가 구매/상환 기능은 미구현**이다.
- 지원금이 남아있는 동안 운행 수익에서 해당 비율을 지원금 잔액 내로 공제, 완납 후 공제 중단.
- 원화 ↔ M 환산 규칙 미정.

## 데이터 승계 / 경로 [확정/구현]
- 기존 v0.07 저장소 **`myon-taxi-v007 / game / main`**를 그대로 사용하고 차량, 자금, 운행 시각/진행률, 운행 횟수, 시 지원금 잔액 및 지원율 등을 이어받는다. **v0.07.01에서 새로 초기화하지 않는다.**
- v0.07 데이터가 없는 사용자에 한해 **`myon-taxi-v006 / game / main`**에서 과거 택시 데이터를 읽어 v0.07 저장소로 **복사하여 승계**한다. v0.06 DB는 수정 또는 삭제하지 않는다.
- 기존 택시가 있는 경우 이미 첫차를 받은 것으로 처리하여 **중복 지급을 방지**한다.
- 새로운 UI 진행 상태(`introDone`, `messageRead`, `firstReply`, `taxiSelected`)를 동일한 v0.07 저장 데이터에 추가해 재접속 시 이어간다.
- 저장 자료 형식을 검증할 수 없는 경우 무작정 초기 데이터로 덮어쓰지 않고 오류를 표시한다.
- 기본: https://myon-world.github.io/MYON/
- 이전 v0.07 택시 화면: 직접 경로 `/MYON/taxi.html` 또는 `?mode=taxi`.
- 이전 임무판: `?mode=missions`, 기존 메뉴: `?mode=legacy`. 이전 경로와 배포 워크플로 유지.
- 배포 커밋별 빌드 ID가 정적 HTML iframe에 붙어 모바일 캐시를 구별한다.
