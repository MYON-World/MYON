# MYON 게임 설계 기준

> 2026-10-26 / v0.08.05
> [확정] 사용자 요구사항 · [현재 구현] GitHub main · [미정] 후속 결정

## 핵심 방향 [확정]
- MYON은 다양한 도시 사건을 다루는 방치형 + 경영 시뮬레이션 게임이며, 교통 전용 게임이 아니다.
- 도시는 본래 불안정하며, 설명문이나 상태 배너로 세계관을 장황하게 표시하지 않는다.
- 게임은 단순히 업그레이드를 늘리거나 연구 버튼을 기다리는 방식에 의존하지 않는다. 플레이어의 선택과 도시에서의 결과를 앞으로 설계한다.

## 초기 화면 [확정/현재 구현]
- 상단 왼쪽 `MYON`, 오른쪽 날짜 `yyyy.mm.dd`(작게)와 **큰 디지털 `HH:MM`**(31px, 360px 이하 화면 27px)으로 구성. 처음부터 한국 표준시(KST)를 보여준다. 1초마다 갱신한다.
- 홈에 모든 분야의 임무가 독립 카드 한 줄로 등장한다.
- 미수락 카드: `임무명 / 폐기 MM:SS / 시작`.
- 진행 중 카드: `임무명 / HH:MM:SS`. 시작 시 완료할 때까지 남은 시간 표시.
- 제목·카운트·예상 보상·자금·그래프·도시 상태 등 요청받지 않은 UI 추가 금지.
- 스크롤 가능한 목록, 보이지 않는 스크롤바, 어두운 청록색 카드.
- 하단 메뉴 4개: **홈 / 메뉴 1 / 메뉴 2 / 설정**. 홈만 개방, 나머지 모두 잠금. 메뉴 1·2는 사용자가 추후 이름과 용도를 지정한다.

## 임무 동작 [확정/현재 구현]
- 도시 임무는 무작위 시각에 등장하고, 시작하지 않으면 기한 후 자연 폐기, 시작하면 완료시각에 자동 종료된다.
- 최대 동시 진행 10건. 한도 수는 숨기며 11번째 시작 시 카드 안에 짧게 `시작 불가`만 표시.
- 기존 임시 밸런스 유지: 최초 3건, 등장 간격 4~8.5초, 미수락 폐기 17~33초, 진행 완료 2~6분.
- v0.08.05부터 시계와 저장은 핵심 기본 기능이다. **시간 연구(24시간), 임시 저장 연구(1시간) 카드 모두 제거.** 필수 시스템을 열기 위한 추가 연구 없음.
- 오프라인 진행이 기본 제공된다. 재접속 시 종료 후 실제 경과시간을 계산해 임무 완료/폐기를 처리하며, 미접속 기간의 임무를 대량으로 누적하지 않는다.

## 저장·데이터 연속성 [확정/현재 구현]
- 브라우저 IndexedDB에 처음부터 자동저장한다. 스냅샷에는 임무 상태와 절대 마감시각, 임무 등장 예정시각, 저장 시각, 다음 ID가 포함된다.
- 저장 DB `myon-v00804-progress`와 저장소 `game`은 유지하지만, v0.08.05는 새로운 레코드 키 `v00805-main`, `schema 2/kind game`을 사용한다.
- 첫 이관 시 구 키 `main`에 보존된 v0.08.04 `schema 1/kind full`의 현재 유효한 일반 임무 기록을 복원하고 새 형식으로 저장한다. 기존 데이터는 삭제하지 않는다.
- 구 키에 `kind research`만 있으면 저장 연구 외 임무 내역은 과거 버전에서 보존하지 않았으므로 새 임무 3개부터 시작한다.
- 이미 종료됐거나 만료된 임무는 종료/폐기되며 남은 임무만 복원한다. 이후에는 v0.08.05 새 키에서 연속적으로 저장한다.
- 예전 v0.07 등 레거시 IndexedDB 및 불필요한 오래된 자료는 삭제하지 않는다.
