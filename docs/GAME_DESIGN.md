# MYON 게임 설계 기준

> 2026-10-24 / GitHub main 기준 **v0.07**
> **[확정]** 관리자의 결정, **[구현]** 코드의 현재 동작

## 기본 방향 [확정]
- 여러 분야를 조금씩 성장시키고 자동화하는 방치형 게임. 첫 분야 **교통 → 택시**.
- 여러 분야가 **하나의 공용 자금**을 공유한다.
- 기존 임무판은 이전 버전 경로로 보존한다. 긴 도입 스토리 대신 첫 접속 시 **버튼 답변형 메신저**로 현재 도시의 교통 문제와 첫 사업을 안내한다.
- MYON 게임 화면 자체가 유저의 회사이며, 별도의 회사 생성 절차는 만들지 않는다.
- v0.07에서 첫 사업으로 실제 구현된 분야는 **교통 → 택시**뿐이다. 다른 분야가 구현되면 이후 선택 가능한 구조를 검토한다.

## v0.07 첫 시작 [확정/구현]
- 새 게임은 기존 v0.06 진행 데이터를 승계하지 않고 공용 자금 **0 M**, 초기 택시 **1대**로 시작한다.
- 첫 화면은 모바일 메신저. 발신자 임시 명칭은 운영 지원팀이며 유저는 미리 작성된 답변 버튼으로만 대화한다.
- 핵심 문구: **“여러 분야의 도움이 필요하지만, 지금은 택시 분야부터 관리해 주셔야 합니다.”**
- 대화 완료 후 MYON 홈으로 이동한다. 대화 완료 상태는 저장되어 이후 접속에 다시 나타나지 않는다.
- 회사 영구 연구, 연구팩, 분야별 업그레이드와 복수 분야 진출은 장기 설계 중이며 v0.07에 아직 구현하지 않았다.
- 동시 관찰 가능 수는 초기 **1대**로 설정한다. 확장 수치·해금 방식은 미확정이다.

## 화면 [확정/구현]
- MYON 로고·날짜·시각, 공용 자금, 홈 → 분야 → 교통 → 택시 메뉴.
- 하단: **← 이전메뉴 | 현 메뉴명 | 홈**.
- **초압축 택시 미터기**: 상단 왼쪽 남은 거리, 상단 오른쪽 남은 시간, 중앙 큰 현재요금, 하단 얇은 진행바만 표시.
- 미터기 안의 차량명·자동운행 상태·예상요금·추가시간 변수 등 문구는 표시하지 않는다.
- 시 지원금 상환은 미터기 바깥에서 조작한다.

## 운행 [확정/구현]
- 택시 최대 보유량 **20대**. 초기 지급 1대, 추가 구매 19대. 다른 교통 분야에는 적용하지 않는다.
- **모든 택시는 시 지원금 미상환 여부와 무관하게 상시 자동운행**. 수동운행 및 ON/OFF 기능 없음.
- 운행 종료 후 자동 정산하고 바로 다음 운행을 시작.
- 거리 약 1~10km, 0.1km 단위 무작위. 예정시간 **1km당 3분**.
- 남은 시간은 초 단위, 남은 거리는 0.1km 단위로 감소.
- 실시간 미터기 요금은 현재까지 주행한 거리에 따라 증가. 최종요금 선표시 없음.
- 교통정체·추가시간·시간 변수 추첨은 삭제.
- 재접속 시 완료된 자동운행을 순서대로 정산(업데이트 한 번에 차량당 최대 5,000회 처리).

## 택시 차량·시 지원금 [확정/구현]
| 항목 | 값 |
|---|---:|
| 차량가격 | 30,000,000M |
| 초기 차량 | 1대 무상 제공 (별도 구매 결제 없음) |
| 초기 시 지원금 미상환액 | 27,000,000M |
| 초기 시 납부율 | 90% |
| 추가 구매 지원 비율 | 0~90% 선택 |
| 추가 구매 자기부담금 | 30,000,000M - 선택한 지원금 |
| 수익의 시 납부 | 해당 차량 지원율만큼, 잔액 이내 |
| 중도·전액 상환 | 공용 자금으로 언제든 가능 |
| 완납 이후 | 시 납부 중단, 수익 100% 공용 자금 유입 |

- 최초 차량가격의 나머지 10% 회계 처리는 별도 확정하지 않고 기존 동작을 보존한다.

## 요금 [확정]
- 기본요금 **4,800M**, 기본거리 **1.6km**.
- 초과 거리 **131m당 100M**.
- 이전의 지연 요금(30초당 100M)은 변수 제거로 정상 운행에서 적용하지 않음. 요금 기준 수치는 임의 변경하지 않는다.
- 원화 ↔ M 별도 환산 규칙 미확정.

## 저장·경로 [구현]
- v0.07 새 게임 IndexedDB: **myon-taxi-v007 / game / main**. 이전 택시 진행 데이터를 승계하지 않는다. 신규 게임을 시작한 이후에는 이 DB의 진행 상태를 보존한다.
- v0.06용 **myon-taxi-v006 / game / main**은 삭제·변경하지 않고 과거 버전용으로 보존한다.
- 정식: https://myon-world.github.io/MYON/
