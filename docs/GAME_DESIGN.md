# MYON 게임 설계 기준

> 2026-10-24 / GitHub main 기준 **v0.07.03**

## 게임 및 화면 [확정/구현]
- MYON 자체가 회사이며 별도 회사 생성 절차가 없다. 모든 분야는 공용 자금 **M**을 공유한다.
- 기본 진입은 항상 **홈**. 하단 메뉴는 **홈 / 운영 / 설정** 3개다.
- **홈**: 자금 표시와 기존 차량의 실시간 운행 미터기.
- **운영**: 신규 사용자에게 **택시 차량 지원받기** 버튼 제공. 지원받으면 홈과 운영에 같은 택시 미터기를 표시한다. 기존 차량 보유자는 지원 버튼 없이 운행 미터기가 나타난다. 하단에서 **차량 구입**과 **시 지원 상환** 메뉴로 이동할 수 있다.
- **차량 구입**: 첫차 지원 후 지원율 0~90%를 선택하여 추가 차량을 구매한다. 구매 가능 여부는 보유 차량 한도(20대)와 현재 자금 및 자기 부담금으로 판단한다. 구매 후 새 차량은 바로 운행한다.
- **시 지원 상환**: 차량별 남은 지원금 확인, 부분 상환 및 전액 상환. 상환액만큼 현재 자금과 해당 지원금 잔액이 감소하며 자동 공제는 계속 적용된다.
- **설정**: 게임 이름과 버전 표시.
- 메신저·대화 시작·메시지 및 알림은 **v0.07.02에서 삭제**한다. 회사 화면 도입은 **보류**한다.
- 신규 사용자의 초기 공용 자금 **0 M**. 최초 지원 차량은 한 번만 지급되며 기존 차량 보유자에게 중복 지급하지 않는다.
- 택시 미터기: 차량 번호, 자동운행 문구, 시 지원 상환액을 노출하지 않는다. **남은 거리 / 남은 시간 / 현재 요금 / 얇은 진행바**만 표시하고 홈과 운영에서 같은 운행 상태를 보여준다.
- 별도 회사/연구 기능은 여전히 보류한다. 기존 운행 수익의 시 지원금 자동 공제는 구매·상환 메뉴와 함께 적용한다.

## 운행/요금 규칙 [기존 구현 유지]
- 보유 택시 최대 **20대**, 시 지원금 완납 여부와 관계없이 모든 차량은 자동 운행한다.
- 거리 1~10km, 0.1km 단위 무작위, **1km당 3분**. 운행 종료 후 자동 정산 및 다음 운행 시작.
- 기본요금 **4,800 M**, 기본거리 **1.6km**, 초과 **131m당 100 M**. 주행 중 현재 거리 기준 미터기 요금 실시간 반영.
- 운행 중 교통정체·추가시간 변수 없음. 재접속 시 각 차량 최대 5,000회씩 완료 운행 정산 처리.
- 차량가격 **30,000,000 M**. 최초 차량은 별도 결제 없이 지급하되 시 지원금 미상환액 **27,000,000 M**, 납부율 **90%**로 시작.
- 추가 차량은 지원율 **0~90%**를 1% 단위로 설정할 수 있다. 지원금 = 차량가격 × 지원율(반올림), 자기 부담금 = 차량가격 - 지원금. 잔액이 자기 부담금 이상이고 첫차를 보유하며 20대 미만일 때만 구매할 수 있다. 구매 즉시 자기 부담금을 차감하고 시 지원금 잔액을 설정한다.
- 직접 상환은 차량별 유효한 양의 정수 금액만 받고 현재 자금 이내에서 진행한다. 상환 요청액이 남은 지원금보다 크면 미상환 잔액만 차감한다. 전액 상환은 남은 지원금을 모두 납부하며, 지급 완료 후 운행 수익에서 시 지원금 공제를 중단한다.
- 지원금이 남아있는 동안 운행 수익에서 해당 비율을 지원금 잔액 내로 공제, 완납 후 공제 중단.
- 원화 ↔ M 환산 규칙 미정.

## 데이터 승계 / 경로 [확정/구현]
- 기존 v0.07 저장소 **`myon-taxi-v007 / game / main`**를 그대로 사용하고 차량, 자금, 운행 시각/진행률, 운행 횟수, 시 지원금 잔액 및 지원율 등을 이어받는다. **v0.07.03에서도 초기화하지 않는다.**
- v0.07 데이터가 없는 사용자에 한해 **`myon-taxi-v006 / game / main`**에서 과거 택시 데이터를 읽어 v0.07 저장소로 **복사하여 승계**한다. v0.06 DB는 수정 또는 삭제하지 않는다.
- 기존 택시가 있는 경우 이미 첫차를 받은 것으로 처리하여 **중복 지급을 방지**한다.
- 이전의 메시지 진행 필드는 화면에서 사용하지 않되, 구버전 저장 데이터의 필드를 임의로 삭제하지 않는다.
- 저장 자료 형식을 검증할 수 없는 경우 무작정 초기 데이터로 덮어쓰지 않고 오류를 표시한다.
- 기본: https://myon-world.github.io/MYON/
- 이전 v0.07 택시 화면: 직접 경로 `/MYON/taxi.html` 또는 `?mode=taxi`.
- 이전 임무판: `?mode=missions`, 기존 메뉴: `?mode=legacy`. 이전 경로와 배포 워크플로 유지.
- 배포 커밋별 빌드 ID가 정적 HTML iframe에 붙어 모바일 캐시를 구별한다.
