# MYON 게임 설계 기준

> 2026-10-27 / v0.08.09
> [확정] 사용자 요구사항 · [현재 구현] GitHub main · [미정] 후속 결정

## 기본 방향
- MYON은 도시의 다양한 사건을 다루는 간결한 방치형 + 경영 시뮬레이션 게임.
- 업그레이드가 많아지면 재미가 떨어지므로 꼭 필요한 기능만 추가하고, 도시 임무 선택과 실제 도시 변화의 게임성은 차후 개발한다.

## 화면 [확정/현재 구현]
- 왼쪽 MYON, 오른쪽 작은 `yyyy.mm.dd` + 큰 24시간제 `HH:MM`, KST 표준시, 1초 틱.
- 카드는 한 줄 `임무명 · 폐기 MM:SS · 시작`(미수락), `임무명 · HH:MM:SS`(진행 중). 제목·건수·자금·추가 상태 배너는 없음.
- 홈 목록은 세로 스크롤, 스크롤바 숨김. 하단 `홈 / 메뉴 1 / 메뉴 2 / 설정` 4개이며 홈만 사용 가능.
- **목록 정렬**: 미수락을 맨 위로 모으고 폐기까지 시간이 짧은 것이 먼저. 그 아래 수락된 임무는 완료까지 남은 시간이 짧은 것이 먼저. 해금 임무도 정렬에 포함.

## v0.08.07 레이아웃 복구 [확정/현재 구현]
- v0.08.05의 HTML·CSS를 화면 기본형으로 사용하며 버전 문자열·엔진 캐시값만 교체한다. 큰 시계, 한 줄 임무 카드, 하단 4개 메뉴와 간격, 색상은 동일하다.
- v0.08.06의 정렬은 기존 DOM 카드의 `style.order` 지정으로 구현한다. `list.append(...nodes)`로 노드를 다시 붙이지 않아 스크롤/화면 점프를 최소화한다.
- 자동수락 해금/24시간 진행, 10분 간격, 1분 쿨타임, 카드 10건 상한 등 0.08.06 기능은 모두 유지한다.

## 임무 제한과 시간 [확정/현재 구현]
- 전체 카드는 **최대 10개**. 미수락 + 수락 + 업그레이드/해금 임무의 합계다. 전체 9개 이하일 때만 무작위 새 임무 등장.
- 동시에 진행하는 수락 임무도 최대 10개. 제한 수치 비노출.
- 일반 임무: 최초 3건, 추가 등장 4~8.5초 무작위, 미수락 폐기 17~33초 유지. 수락 후 게임 소요시간은 임무별 현실시간 기준의 초기 10%(6~72분)에서 시작해 업그레이드 완료에 따라 최대 현실시간 100%까지 증가한다.
- 종료된 임무는 목록에서 사라진다. 오프라인 경과시간을 재접속할 때 계산해 완료/폐기 정산. 미접속 중 무한 임무 누적 없음.
- 시간 표시·기본 IndexedDB 자동저장·오프라인 처리는 처음부터 제공(시간 연구/임시 저장 연구 없음).

## 자동 임무 수락 해금 [확정/현재 구현]
- 특별 카드 `자동 임무 수락`이 다른 임무처럼 무작위로 등장하고 미수락 시 폐기될 수 있다. 플레이어가 직접 시작하면 실제 경과시간 **24시간** 뒤 해금. 다시 등장하지 않음.
- 해금 직후 첫 **1분 쿨타임**. 이후 **10분에 최대 1건** 자동 수락, 각 수락 시 **1분 쿨타임** 적용. 수락 가능 시각을 저장해 재시작해도 제한 유지.
- 자동 수락은 미수락 *일반 임무* 중 폐기 예정시각이 가장 가까운 임무를 수락. 이미 폐기/완료되었거나 여유가 없으면 수락하지 않는다.
- 일반 임무 자동수락도 신규 시간표에 따른다. 자동 수락 해금 임무는 기존 24시간이며 카드/동시 진행 제한에 포함.
- 오프라인 상태에서 24시간 경과로 해금이 완료되면 재접속 시 영구 해금한다. 다만 미접속 동안 신규 임무를 만들어 10분마다 자동 수락한 것으로 소급하지 않는다.

## v0.08.08 임무시간 체계
- 사용자 확정: 일반 임무 32종은 임무별 **현실 작업시간 잠정 추정치의 10%**(90% 단축)를 소요한다. 작업 규모에 따라 현실 작업시간은 달라지므로 이 표는 실측 평균이 아닌 **게임 밸런스용 가정**이다.
- 현실 1시간 → 게임 6분: 생활 물자 운송, 긴급 물자 확보, 지역 의료 물품 확보, 지역 식료품 확보, 복지시설 물품 공급, 공공 급식 공급.
- 현실 2시간 → 게임 12분: 공공시설 점검, 도로 안전 점검, 통신 시설 점검, 정수시설 점검, 주거지역 전기 점검, 상업시설 안전 점검.
- 현실 4시간 → 게임 24분: 지역 전력 공급, 상가 물품 공급, 생활용수 확보, 공장 자재 운송, 가로등 정비, 정류장 시설 보수.
- 현실 6시간 → 게임 36분: 지역 환경 정비, 배수시설 정비, 물류 창고 정비, 공원 시설 정비, 폐기물 처리 지원, 지역 통신망 보수.
- 현실 8시간 → 게임 48분: 노후 시설 보수, 산업 설비 정비, 주거시설 보수, 산업단지 설비 보수, 학교 시설 보수.
- 현실 12시간 → 게임 72분: 노후 배관 교체, 하천 시설 복구, 산업 폐수 정비.
- **자동 임무 수락 해금 임무 24시간은 제외**하고 변경하지 않는다. 자동 수락 주기 10분·쿨타임 1분·전체 카드 10개 상한도 그대로.
- **이미 시작한 임무**의 완료예정시각(finishesAt)은 기존 저장값을 유지한다. v0.08.08 이후 수동·자동으로 새로 수락한 일반 임무부터 새 시간표를 적용한다.
- 임무 등장 간격 4~8.5초, 미수락 폐기 17~33초, 오프라인 진행, 저장 DB `myon-v00804-progress`의 `game/v00806-main` (schema 3), 기존 해금 상태 유지.
- **v0.08.05 레이아웃 고정**: HTML·CSS·카드·시계·하단 메뉴는 손대지 않고 버전 제목과 엔진 캐시 키만 갱신한다.

## v0.08.09 순차적 시간 업그레이드 [확정/현재 구현]
- 32종 일반 임무별 현실 예상시간과 10%/100% 시간표 전체 내용은 **[임무시간 기준표](MISSIONS.md)**에 기록.
- 한 줄 홈 임무로 `임무시간 업그레이드 1`부터 `10`까지 무작위 등장. 사용자가 직접 시작한다. **앞 단계 완료 전 다음 단계 등장 불가**. 동일 단계 2개 동시 생성 불가.
- 연구시간 순서: **5분 / 15분 / 30분 / 1시간 / 2시간 / 3시간 / 6시간 / 9시간 / 12시간 / 24시간**.
- 연구 완료 비율 순서: **15/20/30/40/50/60/70/80/90/100%**, 초기 10%. 새로 수락하는 일반 임무부터 적용한다.
- 미수락 연구는 폐기되면 같은 단계가 재등장할 수 있고, 수락된 연구는 오프라인 경과시간으로 진행한다. 완료 레벨 `timeLevel`을 영구저장.
- 전체 카드 10개 제한과 동시 진행 10개 제한에 업그레이드 포함. **자동 수락은 일반 임무만** 수락하며 연구 임무는 제외.
- 별도 자동 임무 수락 해금 24시간은 비율에서 제외. 기존 저장 임무 완료시각과 해금/쿨타임 보존.
- **0.08.05 화면 디자인 고정:** HTML/CSS는 버전 문자열만 제외하고 그대로 유지.

## 저장/마이그레이션 [확정/현재 구현]
- 동일 IndexedDB `myon-v00804-progress`, objectStore `game`, 새 레코드 `v00806-main` / schema 3.
- 저장 데이터: `savedAt`, `nextId`, `nextArrival`, 일반/해금 임무 종류와 시작·만료·완료 절대시각, `autoUnlocked`, `nextAutoAt`, `cooldownUntil`, `timeLevel`(v0.08.09에서 추가, 0~10).
- 이전 v0.08.05 `v00805-main` / schema 2를 최초 1회 가져옴. 그 키가 없는 기존 기기에서는 v0.08.04 `main` / schema 1의 완료된 저장 연구 기반 전체 스냅샷도 가져옴. 구 자료는 삭제/초기화하지 않음.
- 과거 v0.08.04 저장 연구만 있었고 전체 게임 저장이 미해금인 경우, 당시 일반 임무 기록은 존재하지 않으므로 기본 3건 생성.
