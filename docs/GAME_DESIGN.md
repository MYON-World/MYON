## v0.08 초기 게임 구조 [확정/구현]
- 기본 진입은 `src/App.vue` → `public/myon-v008.html`. v0.07.04 기본 화면은 `?mode=v007` 또는 `/MYON/myon.html`에 그대로 남긴다. `?mode=taxi`, `?mode=missions`, `?mode=legacy`도 보존한다.
- 초반 UI는 상단 MYON 로고, 독립된 임무 카드, 하단 홈/회사/설정이다. 회사와 설정은 잠겨 있고 홈만 이용한다. 임무 목록은 스크롤되지만 스크롤바는 숨긴다.
- 분야 구분, 임무 건수 및 목록 제목, 자금, 시계, 운영 단계, 동시 진행 제한 수, 도착·완료·폐기 시간 및 진행률을 화면에 표시하지 않는다.
- 임무는 무작위 시간에 계속 나타난다. 시작하지 않은 임무는 일정 시간이 지나 조용히 사라지고, 다른 도시 주체가 해결한 것으로 취급한다.
- 플레이어가 직접 '시작'을 누르면 그 카드에는 '임무 진행중'만 보인다. 동시 진행 가능 수는 10건이지만 사전 표시는 하지 않고 초과 시 해당 카드에 '임무를 시작할 수 없습니다.'를 잠시 표시한다. 수락한 임무도 예고 없는 시각에 완료되어 목록에서 사라진다.
- 현재 수치(추후 조정 가능): 등장 간격 무작위 4~8.5초, 미수락 유효 기간 17~33초, 수락 후 완료 2~6분. 이 시간은 화면에서 숨기며 확정 밸런스가 아니다.
- **v0.08 초반은 자동 저장과 수동 저장 기능이 없다.** 열린 페이지의 메모리에서만 작동하므로 새로고침/브라우저 종료 시 v0.08 임무 상태가 사라진다. 이 점은 v0.07의 저장 기록과 독립이다.
- 기존 `myon-taxi-v007 / game / main`과 `myon-taxi-v006 / game / main` 데이터는 v0.08 코드에서 읽기/쓰기/삭제하지 않는다. v0.07.04 코드는 그대로 보관한다. 구버전 자금·차량을 v0.08 신규 게임 데이터로 자동 변환하지 않는다.


## 이후 성장 구조 [방향 확정 / 세부 미정]
- MYON은 교통에 한정하지 않고 불안정한 도시에서 발생하는 다양한 일을 임무로 다룬다. 불안정이라는 세계관을 별도 상태 문구로 강조하지 않는다.
- 처음에는 수동으로 진행하고, 성장 후 자동화가 해금되는 방치형이다. 복합적인 경영 시뮬레이션의 난이도는 성장하면서 증가하지만, 자동화를 통해 느리게라도 운영할 수 있게 하는 방향이다.
- 회사·설정, 시계, 자금 표시, 정보 파악 및 자동화의 해금 시점과 조건, 경제·성장 엔진, 미래 저장 기능은 아직 미정이다. 임의로 확정하지 않는다.

> 2026-10-24 / GitHub main 기준 **v0.07.04**

## 게임 및 화면 [확정/구현]
- MYON 자체가 회사이며 별도 회사 생성 절차가 없다. 모든 분야는 공용 자금 **M**을 공유한다.
- 기본 진입은 항상 **홈**. 하단 메뉴는 **홈 / 운영 / 설정** 3개다.
- **홈**: 자금 표시와 기존 차량의 실시간 운행 미터기.
- **운영**: 신규 사용자에게 **택시 차량 지원받기** 버튼 제공. 지원받으면 홈과 운영에 같은 택시 미터기를 표시한다. 기존 차량 보유자는 지원 버튼 없이 운행 미터기가 나타난다. 하단에서 **차량 구입**과 **시 지원 상환** 메뉴로 이동할 수 있다.
- **차량 구입**: 첫차 지원 후 지원율 0~90%를 선택하여 추가 차량을 구매한다. 구매 가능 여부는 전체 차량 공통 한도(50대)와 현재 자금 및 자기 부담금으로 판단한다. 구매 후 새 차량은 바로 운행한다.
- **시 지원 상환**: 차량별 남은 지원금 확인, 부분·전액 상환. 상환액만큼 자금과 지원금 잔액이 감소하며 운행 수익 자동 공제를 유지한다. 완납 차량은 판매 버튼으로 차량가의 50%에 판매한다.
- **설정**: 게임 이름과 버전 표시.
- 메신저·대화 시작·메시지 및 알림은 **v0.07.02에서 삭제**한다. 회사 화면 도입은 **보류**한다.
- 신규 사용자의 초기 공용 자금 **0 M**. 최초 지원 차량은 한 번만 지급되며 기존 차량 보유자에게 중복 지급하지 않는다.
- 택시 미터기: 차량 번호, 자동운행 문구, 시 지원 상환액을 노출하지 않는다. **남은 거리 / 남은 시간 / 현재 요금 / 얇은 진행바**만 표시하고 홈과 운영에서 같은 운행 상태를 보여준다.
- 별도 회사/연구 기능은 여전히 보류한다. 기존 운행 수익의 시 지원금 자동 공제는 구매·상환 메뉴와 함께 적용한다.

## 운행/요금 규칙 [기존 구현 유지]
- **MYON 전체 차량 최대 50대**(차종 공통). 현재 구현 차량은 택시뿐이며 향후 다른 차량 분야도 이 한도를 함께 사용해야 한다. 초과 기존 데이터는 보존하며 신규 구매만 차단한다. 시 지원금 완납 여부와 관계없이 모든 차량은 자동 운행한다.
- 거리 1~10km, 0.1km 단위 무작위, **1km당 3분**. 운행 종료 후 자동 정산 및 다음 운행 시작.
- 기본요금 **4,800 M**, 기본거리 **1.6km**, 초과 **131m당 100 M**. 주행 중 현재 거리 기준 미터기 요금 실시간 반영.
- 운행 중 교통정체·추가시간 변수 없음. 재접속 시 각 차량 최대 5,000회씩 완료 운행 정산 처리.
- 차량가격 **30,000,000 M**. 최초 차량은 별도 결제 없이 지급하되 시 지원금 미상환액 **27,000,000 M**, 납부율 **90%**로 시작.
- 추가 차량은 지원율 **0~90%**를 1% 단위로 설정할 수 있다. 지원금 = 차량가격 × 지원율(반올림), 자기 부담금 = 차량가격 - 지원금. 잔액이 자기 부담금 이상이고 최초 차량을 지급받은 이력이 있으며 MYON 전체 차량이 50대 미만일 때만 구매할 수 있다. 구매 즉시 자기 부담금을 차감하고 시 지원금 잔액을 설정한다.
- 직접 상환은 차량별 유효한 양의 정수 금액만 받고 현재 자금 이내에서 진행한다. 상환 요청액이 남은 지원금보다 크면 미상환 잔액만 차감한다. 전액 상환은 남은 지원금을 모두 납부하며, 지급 완료 후 운행 수익에서 시 지원금 공제를 중단한다.
- 지원금이 남아있는 동안 운행 수익에서 해당 비율을 지원금 잔액 내로 공제, 완납 후 공제 중단.
- **판매**: 시 지원금 잔액 **0 M**인 차량만 판매 가능. 가격은 최초 차량가의 **50% 고정**(현재 택시 15,000,000 M), 판매 시 차량 제거와 자금 지급을 동시에 적용. 운행 중 작업은 제거, 첫차 지급 이력은 유지해 재지급을 막는다. 판매 후 전체 차량이 50대 미만이면 재구매할 수 있다.
- 원화 ↔ M 환산 규칙 미정.

## 데이터 승계 / 경로 [확정/구현]

- 이전 v0.07 택시 화면: 직접 경로 `/MYON/taxi.html` 또는 `?mode=taxi`.
