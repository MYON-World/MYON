# MYON 리온 고유 ID 및 종류별 넘버링 · v1

> 2026-11-18 최초 등록. **v0.13.96부터 리온 발견 0단계와 게임 UI에 연결합니다.**

## 원본과 관리 범위
- GitHub `main`에 있는 `data/rions/registry.v1.json`이 리온 원본 신원 등록부입니다.
- `data/rions/id-lock.v1.json`은 최초 발급된 ID·번호와 구 임무 인덱스를 보호하는 잠금 기록입니다.
- 역할 리온 4종, 플레이형 리온 5종, 분야별 리온 150종 = 총 **159종**.
- 분야별 목록은 `public/myon-world-baseline.json`의 15개 계열 × 10개 분야에 대응합니다.
- 공개 게임 정의는 `public/myon-rion-registry.json`에 동기화되어 개발서버 런타임에 제공됩니다. 정식·정식 가속의 고정 승인 버전은 유지합니다.

## 두 가지 영구 식별자
1. `id`: 기계가 참조하는 **영구 ID** (예: `rion.role.ui`, `rion.field.mission-01.01`).
2. `number`: 종류별로 독립 부여하는 **영구 번호** (예: `USR-000001`, `AGR-000001`, `LOG-000001`).

- 번호는 `접두어-6자리 숫자`이며 접두어마다 `000001`부터 시작합니다.
- 원칙적으로 ID/번호를 다시 발급하지 않습니다. v0.13.96에서 사용자 승인으로 `유저→UI`, `백과→위키` **두 식별자만 예외 변경**하며 `data/rions/id-aliases.v1.json`에 이전 값들을 영구 예약하고 세이브를 마이그레이션합니다.
- 삭제 대신 폐기 표시를 사용하고 폐기된 번호도 **절대 재사용하지 않습니다**.
- 신규 리온은 기존 레코드 사이에 삽입하지 않고 **끝에 추가**하며, 해당 접두어의 미사용 다음 번호를 발급합니다.
- ID와 번호는 모두 중복 금지입니다. 종류별 번호만으로 식별하지 않고 전체 접두어까지 함께 사용합니다.

## 종류별 접두어
- 역할: `UIR` UI · `DEV` 개발 · `WIK` 위키 · `NAR` 스토리
- 플레이: `OBS` 관전 · `MGT` 경영 · `CRE` 창작 · `EXP` 탐험 · `STY` 스토리형
- 분야: `AGR` 농업 · `LFS` 축산수산임업 · `RES` 광업자원 · `MFG` 제조가공 · `ENE` 에너지 · `CON` 건설시설 · `TRN` 교통 · `LOG` 물류 · `COM` 상업금융 · `CUL` 관광문화 · `EDU` 교육연구 · `MED` 의료복지 · `ENV` 환경생태 · `PUB` 공공안전 · `TEC` 정보기술

## 구버전 인덱스 보호
- 기존 게임의 150개 분야는 0~149 배열 인덱스를 사용합니다.
- `legacyFieldIndex`는 **기존 번호와 신규 ID의 1회성 대응표**이지 영구 ID가 아닙니다.
- 초기 150종의 기존 배열 위치와 연결을 절대 이동하거나 재지정하지 않습니다. 추가 분야도 배열 순서로 신원 ID를 생성하지 않습니다.

## 유저 상태와 발견
- 발견하지 않은 리온은 유저 세이브에 기록하지 않습니다. **기록 없음 = 미발견**, 발견 시 처음으로 `stage:0` 상태를 기록합니다.
- 리온의 기본 정의와 ID는 GitHub가 보관하며, 유저의 발견·단계·관계·임무 진행 상태는 유저 세이브에만 기록하도록 설계합니다.
- UI 리온 미발견 시 하단 리온 메뉴 없음, 위키 리온 미발견 시 지식정보창 없음. 미발견이어도 기존 세계는 정상 작동합니다.
- 각 분야에 실제 엔티티가 여러 개 생성될 경우 '정의 ID'와 '개별 인스턴스 ID'를 추가로 분리합니다. 인스턴스 ID 규격은 추후 별도 결정합니다.

## 안전 검사
- `tests/rion-identity.test.cjs`는 ID 중복, 번호 중복, 접두어·일련번호, 150개 분야의 원래 대응 관계, 등록부·잠금 목록 일치 여부를 검사합니다.
- 다음 커밋부터는 이전 커밋의 잠금 목록과 비교하여 기존 항목의 수정·삭제·순서 변경을 차단합니다.
- 개발은 `main` 최신 커밋, 정식과 정식 가속은 관리자 승인 SHA 고정입니다. 리온 등록으로 정식 승격을 자동 수행하지 않습니다.
- 공개 저장소에 비공개 이야기 설정을 추가하지 않습니다.

## v0.13.96 적용 범위
- 발견은 159종 중 미발견 1종만 선발하고, 최대 24시간 안 무작위 도착하는 `??` 임무로 등장합니다. 60분 만료, 비용 및 금전 보상 없음, 수락 즉시 stage 0입니다.
- UI 리온이 없으면 이름 등 정체가 숨겨지고 리온 메뉴가 나타나지 않습니다. 위키 리온 0은 UI 리온이 있을 때 발견 이름 목록만 제공합니다.
- 신규 일반 임무의 기여 대상은 **당시 발견된 150종 분야 리온** 중 하나로 고정합니다. 기존 임무의 표시·기여량·정산은 소급 변경하지 않습니다.
- 관전·경영·창작·탐험·스토리형 리온 0단계는 발견 상태만 기록합니다. 역할/보너스 1단계 이상은 미구현입니다.
- 개발 리온 0의 공식서버 알림은 새 **승인된** 정식 빌드가 있을 때만 표시하며, 개발서버 기존 알림은 항상 동작합니다.
- 등록부는 GitHub 원본이며, 유저별 발견 기록은 서버별 임무 세이브에 저장합니다. 정식 승격은 별도 관리자 지시가 필요합니다.
