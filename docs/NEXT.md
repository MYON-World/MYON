# MYON 다음 작업 인계
> 기준: 2026-10-25 / v0.08.03 수정 커밋

## 수정한 오류
- **v0.08.02는 저장 기능이 없는 버전**이었고, 첫 v0.08.03 커밋에서 저장 복원과 함께 오프라인 경과시간 처리가 잘못 들어갔음.
- 이번 수정에서는 v0.08.03이라는 버전 번호를 유지하고, 구동 중에만 임무·연구·임무 폐기·임무 등장 대기가 진행되도록 변경.
- 브라우저 종료·새로고침·백그라운드로 숨긴 동안 시간 진행은 멈춤. 재접속/복귀할 때 **마지막 저장 당시 남은 시간부터** 카운트 재개.
- 1시간 임시 저장 연구 시작 직후에는 이 연구만 IndexedDB에 저장하고, 완료 후 전체 게임 상태를 자동 저장.
- 진행 중 연구(시간 연구, 저장 연구 포함)와 일반 임무를 합쳐 동시에 최대 10건. 숫자는 표시하지 않으며 초과 시 짧은 '시작 불가'만 표출.
- 시계는 연구 해금 후 KST 실제 날짜·시각 표시. 저장자료 내보내기·불러오기 및 오프라인 진행은 설정 해금 후 연구할 미구현 항목.
- 기존 저장소는 `myon-v008-progress`; 기존 v0.08.03 저장 레코드도 읽어 새 규칙으로 복원(이전 형식에는 최종 접속 시각이 없어 최초 전환의 정확한 남은 시간은 추정).

## 동작/구현
- 홈의 개별 카드·스크롤바 숨김·회사/설정 잠금·시간 연구 및 저장 연구의 무작위 등장 유지.
- `public/myon-engine.js`에서 IndexedDB 상태 저장 시 `savedAt` 기록. 로드시 종료 중 경과 시간을 마감 시각 등에 다시 더해 정지 효과 구현.
- 페이지 숨김/종료 시 타이머 정지, 복귀 시 게임상 타이머를 이동시켜 남은 시간을 유지.
- 1초 틱, 저장/연구 중에는 주기적인 상태 저장(최대 약 5초 간격)과 상태 변경 시 저장.
- 새 버전 출시 전 개발자 테스트에서 초기 저장 연구→복원, 1시간 연구 완료→전체 자동 저장, 시간 연구 복원, 숨김 상태 정지, 통합 10건 제한을 검증.
- 실제 모바일 브라우저·강제 종료 등 실기기 확인은 별도.

## 이후 설계
- 오프라인 진행은 설정에서 별도 연구로 해금할 예정. 이번에는 자동 해금하지 않음.
- 저장자료 내보내기/불러오기도 설정 메뉴 오픈 후에만 등장.
- 회사/설정/자동화 연구 해금 및 게임 성장 구조는 사용자 추가 확정 대기.
