# MYON 비서 UI 개선 — v0.13.14 (2026-11-11)

## v0.13.14 정식 변경
- 상단 톱니바퀴 옆의 가속 아이콘 및 표시 토글 기능은 모두 제거한다. 추후 시간 가속 기능은 비서 임무에서 제공하는 소모형 가속권으로 별도 설계한다(현재 미구현).
- 비서 카드 제목 옆에 작은 `개발중` 태그를 표시한다. 향후 개발 중인 카드에는 같은 태그 스타일을 재사용한다.
- 이미 실제 임무 목록에 있는 내용과 중복되는 `진행 중인 임무 상세` 드롭다운과 그 데이터용 DOM을 제거한다.
- `진행 중인 임무`, `분석 후 완료 임무`를 각각 가로 100% 통계 카드로 위아래 배치한다. 집계 방식은 변경하지 않는다.
- 비서 24시간 분석·상단 고정·오프라인 집계, 정식 임무 시스템 및 기존 IndexedDB `v01302-world`, 비서 `v01313-assistant` 저장을 유지한다.
- 버전 표기는 `X.YY.ZZ`로 통일한다. 커밋마다 마지막 자리 +1, 99 다음은 자리 올림. 여러 개선을 한 번에 커밋해도 한 단계만 증가한다.

## 과거 버전 — v0.13.13

## v0.13.13 정식 복원
- 기존 DEV/TEST에 있던 비서 분석 카드를 정식 MYON에 복원한다.
- 시작 시각 기준 현실 24시간 동안 임무 분석 후 상단 고정해 지속 분석한다.
- 진행 중인 임무 수와 **분석 시작 이후 완료된 임무 수**, 현재 임무별 예상 완료까지 남은 시간을 표시한다.
- 분석 자료는 게임 저장 키 `v01302-world`에 추가하지 않고, 같은 IndexedDB 스토어의 새로운 키 `v01313-assistant`에 별도 저장한다.
- 오프라인 복귀 시 기존 게임의 정식 소급 계산을 먼저 완료한 다음, 비서 누적 분석 수치를 복원한다.
- 비서는 지금은 읽기 전용 관전자이며 임무, 자금, 배차, 시간 속도를 변경하지 않는다.

## 과거 설계 — v0.13.12

## v0.13.12 이번 단계
- `24배 빠르게`라는 글자를 제거하고 톱니바퀴 옆에 아이콘 전용 버튼을 배치한다.
- 첫 상태는 빨리감기 ▶▶, 버튼을 누르면 일반 재생 ▶, 다시 누르면 ▶▶로 토글한다.
- 이 토글은 화면에서만 유지한다. 새로고침 시 ▶▶로 초기화하며 실제 시뮬레이션 속도, 기존 임무, IndexedDB와 오프라인 진행에는 아무 영향이 없다.
- 추후 실제 가속 기능과 자금 MOD 상호 배제 규칙을 별도 설계·승인 후 구현한다.

## 이전 단계 — v0.13.11

## v0.13.11 이번 단계
- 기존 MYON 상단 왼쪽 MYON 로고와 비활성 톱니바퀴 바로 옆에 `24배 빠르게` 버튼을 배치한다.
- 버튼은 `disabled`이고 어떤 이벤트나 시간 계산에도 연결하지 않는다. 실제 플레이 속도는 기존 1배속 그대로다.
- 추후 버튼을 사용할 수 있게 되면 정상 속도일 때는 `24배 빠르게`, 가속 중일 때는 `정상속도`를 표시하는 계획이다.
- 전체 임무 리스트와 게임 운영·오프라인 저장은 단일 정식판 기준으로 유지한다.
- 장래의 자금 MOD는 기본 리얼 시간 규칙에서만 동작하고, 24배 가속 중에는 비활성화하는 방향을 논의 중이다. 이번 커밋에서는 구현하지 않는다.

## 기존 기준 — v0.13.10

## 현재 확정된 기준
- `main` 정식 게임 한 가지를 기준으로 운영한다. 다른 환경의 공개 사이트와 환경 전환 메뉴는 제거한다.
- 기존 v0.13.09 임무 시스템을 v0.13.10에서도 유지한다: 시간당 신규 임무 1회 시도, 동시 최대 30개, 임무별 진행·종료.
- 기존 정식 저장은 `myon-v00804-progress` 데이터베이스, `game` 스토어, `v01302-world` 키를 그대로 사용한다. 과거 데이터/스키마를 삭제하거나 초기화하지 않는다.
- 사용자가 오프라인이었던 시간에도 임무 생성·진행·완료를 소급 계산한다.
- 좌측 상단 톱니 아이콘만 유지하며 연결된 설정 기능은 아직 없다.
- GitHub Pages는 `main` 브랜치의 `dist/`만 배포한다.
