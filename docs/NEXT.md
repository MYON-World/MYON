# MYON 관전 분석 자동 비서전환 — v0.13.18 (2026-11-12)

- 분석 시작부터 관전임무 분석 카드는 **항상 임무 목록 최상단 고정**. 현실시간 24시간 경과 및 분석 진행률·통계는 유지.
- 분석 시작 24시간 시점에 **수락·별도 연구 없이 자동 '비서' 전환**. 구버전의 전환 연구 대기/등장/수락 진행자도 24시간 경과했다면 즉시 전환하며 실제 24시간 종료시각을 기존 progression.convertedAt에 저장. 비서의 분석 시작시간과 월드 임무는 초기화하지 않음.
- 최초 24시간 분석 중: '관전임무 분석중'+'개발중', 이후: '비서'+'개선중'. 개선중은 수동으로 완료 판단 후 추후 버전에서 제거할 임시 태그.
- 기존 변경기록/설정 및 하단메뉴 **새 연구 제안은 일시 중단**. 진행 중이던 이미 수락된 연구는 원래 완료 시각에 해금을 적용하되 추가 제안 없이 정지. 이전 연구/해금/설정 데이터 유지. 해금된 홈·캐릭터/변경사항 알림/설정 기능도 보존.
- 기존 23종 관전 임무, 정각 배정, 진행 중 운행, 저장 및 오프라인 계산 모두 불변. 연구 단계 DB 스키마 변경하지 않음.

# MYON 관전 임무 매시 정각 배정 — v0.13.16 (2026-11-11)

## v0.13.16 정식 변경
- 새 관전 임무 배정 시각은 매시 정각(HH:00:00). 기존 23종 랜덤·최대 30개 제한·공급 대기 유지.
- 저장된 기존 `nextSupplyAt` 카운트가 있다면 **그 시간에 한 번 임무 공급을 처리한 뒤** 다음 카운트부터 정각에 맞춘다. 기존 시간은 앞당기지 않으며 중복 공급하지 않는다.
- 새로 시작하는 세계는 다음 정각을 첫 공급 시각으로 정한다. 구버전 데이터 이관 시 유효한 기존 카운트는 한 번 유지한다.
- 오프라인 재생은 시간순이며 IndexedDB 월드 키 `v01302-world` schema2, 비서·진행 키와 이전 임무 유지.
- 비서전환 후 선택형 임무 및 비서 카드 문구 정리는 이후 버전에서 구현.

# MYON 비서 연구·알림 해금 — v0.13.15 (2026-11-11)

## v0.13.15 정식 기능
- 관전 분석 24시간 후 비서전환 임무를 별도 카드로 랜덤 제공. 제목 오른쪽 '수락', 미수락 시 임무 폐기(유효 2~4시간)·1~4시간 뒤 무작위 재등장. 1시간 진행 후 팝업 없이 상단 카드명만 '비서'로 변경.
- 비서전환 완료 이후 '변경기록 알림서비스 연구'(1시간) → '설정 시스템 연구'(24시간)를 순서대로 별도 선택형 카드로 제공. 수락된 연구는 오프라인에서도 완료.
- 변경기록 알림 연구가 완료되면 톱니바퀴 옆 최신 버전, 별도의 '시스템' 태그가 있는 24시간 변경기록 카드를 표시. 첫 알림은 연구가 완료된 실제 시각부터 시작하며, 새 버전 감지 시 즉시 교체해 24시간 새로 시작.
- 기존 알림은 새 버전에 덮이거나 24시간 종료 시 삭제. 과거 변경기록을 게임 안에서 열람하는 화면은 아직 없음.
- 설정 연구 완료 후에만 톱니바퀴 버튼으로 '변경기록 알림' 켜기/끄기가 가능. 기본 켜짐, 꺼도 알림 만료시각 불변, 재접속 시 설정 유지.
- 현재 버전의 유저용 업데이트 공지는 `public/myon-release.json`에서 관리하며, 페이지가 열려 있어도 주기적으로 새 릴리스 공지를 감지한다. 앞으로 매 커밋에 릴리스 내용을 작성할 것.
- 새 IndexedDB 키는 `game/v01315-progression` (schema1)뿐. 기존 `game/v01302-world` (schema2), `game/v01313-assistant` (schema1) 및 기존 임무 배정/엔진/저장 호환 유지.
- 연구·알림카드는 자동 임무 30개 제한에서 제외. 연구 대기/폐기 난수는 정식 임무 RNG와 분리. 속도 가속권과 재정 MOD는 아직 미구현.

# MYON 비서 UI 개선 — v0.13.14 (2026-11-11)

## v0.13.14 정식 변경
- 상단 톱니바퀴 옆의 가속 아이콘 및 표시 토글 기능은 모두 제거한다. 추후 시간 가속 기능은 비서 임무에서 제공하는 소모형 가속권으로 별도 설계한다(현재 미구현).
- 비서 카드 제목 옆에 작은 `개발중` 태그를 표시한다. 향후 개발 중인 카드에는 같은 태그 스타일을 재사용한다.
- 이미 실제 임무 목록에 있는 내용과 중복되는 `진행 중인 임무 상세` 드롭다운과 그 데이터용 DOM을 제거한다.
- `진행 중인 임무`, `분석 후 완료 임무`를 각각 가로 100% 통계 카드로 위아래 배치한다. 집계 방식은 변경하지 않는다.
- 비서 24시간 분석·상단 고정·오프라인 집계, 정식 임무 시스템 및 기존 IndexedDB `v01302-world`, 비서 `v01313-assistant` 저장을 유지한다.
- 버전 표기는 `X.YY.ZZ`로 통일한다. 커밋마다 마지막 자리 +1, 99 다음은 자리 올림. 여러 개선을 한 번에 커밋해도 한 단계만 증가한다.
