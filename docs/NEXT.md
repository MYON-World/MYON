# MYON 다음 작업 인계
> 기준: 2026-10-27 / v0.08.10

## 긴급 수정: 연구 임무 자동 수락 제외
- v0.08.09에도 후보 필터 `kind === 'normal'`은 있었지만, 시작 함수에는 자동 시작 전용 차단이 없었다.
- v0.08.10에서 `eligibleForAutoAccept`로 임무 종류·등록 이름·미수락·만료시각 확인, 후보 필터와 `startMission(m, at, 'auto')` 실행부 두 곳에서 검증한다.
- 임무시간 업그레이드 1~10 전부와 자동수락 해금 임무는 자동 시작 불가. 연구는 반드시 수동 시작.
- 연구만 남았을 때는 자동수락 간격·쿨타임 소모 없음. 일반 임무 자동수락/폐기 임박순은 기존대로.
- 모의 DOM·IndexedDB 26개 항목 통과: 10단계 자동 제외, 일반 임무 자동 수락, 수동 연구 진행, 저장과 오프라인 완료, 기존 완료시각 유지.

## 기존 기능과 저장 유지
- 32개 일반 임무 현실시간표, 초기 10% → 10회 연구 후 100%, 단계별 연구시간 5분~24시간 유지.
- 자동 수락 해금 연구 24시간, 자동 수락 최대 10분 1회, 1분 쿨타임, 전체 카드 10개 제한 유지.
- IndexedDB `myon-v00804-progress/game/v00806-main` (schema 3) 재사용: 기존 임무·시간 연구·자동수락 해금·쿨타임·단계 데이터 초기화 금지.
- 사용자 고정 지침: 0.08.05 HTML/CSS 고정, 화면 디자인 추가/변경 금지. `public/myon.html`은 버전만 갱신.
- 32종 일반 임무 및 업그레이드 10회 전체 시간표는 `docs/MISSIONS.md`.
