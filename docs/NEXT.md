# MYON 다음 작업 인계

> 기준일: 2026-10-23
> 현재 버전: **v0.06.02**
> 상태: **초압축 택시 미터기·전 차량 자동운행 반영**

## 반영된 최신 기능
- 택시 20대 총 보유 제한(다른 교통 분야에는 적용되지 않음).
- 최초/추가 차량 모두 구매·지원금 상환 여부와 무관하게 자동운행.
- 거리 0.1km 단위 감소, 정상 운행시간 1km당 3분, 운임 실시간 증가.
- 교통정체·추가시간 변수 제거, 최종 예정요금 선표시 제거.
- 미터기 요소는 거리·남은 시간·현재요금·얇은 진행바만.
- 차량가격·지원금 비율·공용 자금·중도 상환 유지.
- 기존 `myon-taxi-v006` DB 및 이전 버전 경로 보존, 이전 운행 진행률 변환.
- 공개 테스트 버튼·별도 테스트 보드 제거.
