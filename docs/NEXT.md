# MYON 다음 작업 인계

> 기준일: 2026-10-25
> 현재 버전: **v0.08**
> 대상: 모바일 우선 / 기본 화면 전체 재설계

## 이번 구현
- 신규 `public/myon-v008.html`을 메인으로 사용. `?mode=v007`에서 기존 0.07.04 진입 가능하며 기존 `public/myon.html`·택시·임무판·legacy 경로를 변경하지 않는다.
- 상단 MYON만 표시, 하단 홈/회사/설정(회사·설정 잠김), 임무별 분리 카드, 세로 스크롤 허용 및 스크롤바 숨김.
- 지역·분야별로 나누지 않고 임무를 하나의 시간 흐름에 따라 등장시킨다. 초기 3건, 이후 무작위 등장, 시작하지 않은 사건은 기한 종료 시 삭제(다른 도시 주체가 해결한 것으로 간주).
- 임무 '시작' 후 '임무 진행중'만 표시, 완료 및 발생·폐기 시간/진행률 숨김. 완료 시 카드 제거.
- 동시 10건 진행 제한은 사전 비노출; 초과 시 '임무를 시작할 수 없습니다.'만 일시 노출.
- 자금, 시계, 도시 불안정 상태, 운영 단계, 임무 제목/개수, 자동/수동 표시, 부가설명 없음.
- 신규 초반 버전은 저장 기능 전혀 없음(메모리만); 구버전 IndexedDB는 접근하지 않아 보존.
- 잠정 내부 시간: 등장 4~8.5초, 미수락 폐기 17~33초, 수락 후 완료 2~6분.

## 확인 항목

- 실제 배포 후 모바일에서 임무 생성/폐기/완료, 수동 시작, 10건 제한, 스크롤바 숨김, 구버전 보존 확인 필요.
- 게임의 다음 단계와 자동화·저장 해금은 관리자와 추가 설계 전까지 구현하지 않는다.
