# MYON 다음 작업 인계
> 기준: 2026-10-28 / v0.09.00

## 이번 버전의 실제 구현
- 하단 첫 번째 `운영 종합판`(기존 임무 목록 유지), 두 번째 `운영` 활성화. 세 번째 `메뉴 2`, 네 번째 `설정` 잠금.
- 운영 화면은 기존 색상/형태의 가로 100% 카드 7개를 세로 배치: 택시·트럭·버스·철도·항공·선박·우주.
- 택시 카드만 클릭 가능하며 택시 운영 영역 진입/복귀. 택시 구매·업그레이드 실기능은 가격/조건이 아직 미정이므로 안내만.
- 트럭부터 우주까지 나머지 여섯 분야는 `준비중`, 잠금 아이콘, disabled 상태.
- 기존 상단 MYON/KST 시계와 기본 임무 리스트, 임무 진행/자동수락/연구/오프라인 저장 모두 유지.
- 동일 IndexedDB `myon-v00804-progress/game/v00806-main` 스키마 3 유지. 엔진 JS에는 변경 없음.

## 사용자 확정 후속 방향 — 미구현
- 기존 운영 종합판의 임무카드는 추후 차량카드로 바꿀 예정. 카드 2행 2열 구성: 차량명/남은시간, 간단상세/정산금.
- 차량은 종류 불문 보유 합산 최대 30대. NPC는 차량에 고정. 철도는 편성 한 개 = 차량 한 대이며 객차 증결은 편성 내부.
- 운영 메뉴에서 운송 종류별 구매·업그레이드 담당. 택시부터 실기능 설계 예정.
- 레벨/EXP 시스템 없음. 실제 차량 가격, 임무/운행 방식, 구매, 자금, 정산은 아직 설계·승인되지 않음.
- 사용자가 지시하지 않은 미리보기 추가/상세 화면/차량 자동 생성/진행 초기화 금지.
