# MYON 다음 작업 인계
> 기준: 2026-10-27 / v0.08.09

## 0.08.09 반영 내용
- **임무별 현실시간표 32종**과 10% 시작/100% 완료 시간을 `docs/MISSIONS.md`에 전체 정리.
- **시간 업그레이드 10회**를 기존 홈 임무 목록에 랜덤 등장하는 수동 시작 카드로 추가. `1회 완료 → 2회 등장`처럼 순차적으로만 가능. 단계 중복 생성/건너뛰기 금지.
- 연구시간은 5분, 15분, 30분, 1시간, 2시간, 3시간, 6시간, 9시간, 12시간, 24시간.
- 일반 임무 작업시간 비율은 최초 10%, 완료 단계마다 15/20/30/40/50/60/70/80/90/100%. 연구 총합 57시간 50분.
- 새 일반 임무 수동/자동 수락에만 현재 비율 적용. 기존 시작된 임무의 `finishesAt`은 변경 없음.
- 시간 업그레이드 연구도 오프라인 진행, 10개 카드·동시 진행 10개 제한 포함. 자동 수락 대상에서는 제외.
- 자동 수락 기능 해금 임무의 24시간, 자동 수락 10분 간격·1분 쿨타임, 카드 정렬, 미수락 폐기/새 임무 등장 시간은 변경하지 않음.
- IndexedDB 기존 키 `myon-v00804-progress/game/v00806-main` 스키마 3 유지. `timeLevel` 필드(0~10)만 추가. 구 저장은 0단계부터 시작하며 기존 해금/임무/쿨타임 기록 이어받음.
- **레이아웃 변경 없음.** 0.08.05 HTML/CSS를 유지하고 문서 제목·엔진 버전 쿼리만 교체.
