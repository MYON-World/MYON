## 현재 플레이
- 상단 MYON, 개별 임무 카드, 하단 홈/회사(잠김)/설정(잠김).
- 분야 통합, 무작위 등장/미수락 소멸, 시작 버튼, '임무 진행중', 동시 10건 비공개 제한.
- 시계/자금/시간/진행률/건수/도시 상태/운영단계 표시 없음.
- 임무 목록만 스크롤되며 스크롤바는 숨김.
- 현재 내부 임시시간: 최초 3건, 등장 간격 4~8.5초, 미수락 폐기 17~33초, 완료 2~6분.
