# MYON 다음 작업 인계
> 기준: 2026-10-27 / v0.08.13

## 이번 변경: 분야 선택 태그 제거
- v0.08.12에서 추가했던 상단 분야 선택 태그 8개 및 선택/필터 로직을 완전히 삭제했다. 게임은 **항상 전체 임무 목록만 표시**한다.
- 도시 32종과 교통(택시·버스·철도·항공·선박·우주) 30종, **일반 임무 총 62종**은 유지한다.
- 각 카드 제목의 `[도시]`, `[택시]`, `[버스]` 등 분야 표시는 그대로 유지하고, 도시/교통을 그룹으로 묶거나 필터하지 않는다.
- 기존 정렬 유지: **미수락 먼저, 폐기시각 빠른 순** → 그 아래 진행 중인 임무 **완료시각 빠른 순**. CSS `style.order` 방식으로 DOM 요소 재삽입 없이 정렬.
- 태그 영역과 해당 CSS만 삭제. **v0.08.05 상단 MYON+KST 시계·기본 한 줄 카드·하단 4개 메뉴 레이아웃 원형 유지**.

## 기존 게임 규칙 유지
- 전체 카드 최대 10개, 초기 3개, 새 임무 등장/미수락 폐기 시간은 시간 연구 0~10회 비율표에 따른다.
- 도시+교통 일반 임무 62종은 자동 수락 대상, 자동 수락 해금(24시간)과 시간 업그레이드 1~10회는 수동 수락 전용.
- 10단계 시간 연구(10%→100%), 자동 수락 10분 간격/1분 쿨타임, 실제 오프라인 경과 진행 유지.
- IndexedDB `myon-v00804-progress/game/v00806-main` schema 3, `timingVersion:1` 및 이미 저장된 임무·절대 만료/완료시간·해금/연구 진척 유지. 저장 마이그레이션이나 초기화 없음.
- 전체 임무명/시간표는 `docs/MISSIONS.md`를 참조.

## 검증
- 변경된 게임 엔진은 모의 DOM/IndexedDB에서 **41개 기능 검사 통과**: 62종, 분야 접두어, 모든 카드 표시, 만료/완료 임박순 정렬, 스크롤/DOM 유지, 시간 연구, 자동 수락, 10개 카드 제한, 저장/재접속.
- GitHub Actions 빌드·배포는 커밋 후 별도 확인할 것.
- 실제 스마트폰 장시간 플레이·재접속은 추가 확인 필요.

## 후속 지침
- 사용자의 명시적 요청 없이 분야 태그/필터나 기타 UI를 다시 추가하지 않는다.
- 0.08.05 기본 레이아웃 및 기존 저장자료 보존. 추가 변경·커밋은 명시적 사용자 요청시에만.
