# MYON 다음 작업 인계

> 기준일: 2026-10-24
> 기능 버전: **v0.07.04**
> 상태: **MYON 전체 차량 50대 공통 제한 / 완납 차량 50% 판매 / 기존 자료 승계**

## v0.07.04 구현
- 홈 / 운영 / 설정 및 기존 자동운행·미터기·요금·시 지원금 상환 규칙 유지.
- 차량 구입은 종류와 관계없이 MYON 전체 50대 한도를 적용한다. 현재 차량 분야는 택시뿐이므로 `vehicleCollections()`에 `state.cars`만 연결했다. 화물차 등 다른 분야 추가 시 같은 목록에 연결해야 한다.
- 보유 50대 이상에서 추가 구입 차단. 기존 기록의 차량 수가 50대를 초과해도 삭제하거나 초기화하지 않는다.
- 지원금이 0 M인 택시만 판매 가능. 택시 판매가는 15,000,000 M(가격 30,000,000 M의 50%). 확인 후 차량을 제거하고 판매금을 자금에 추가한다.
- 전 차량 판매 시 첫 차량 지원 버튼을 다시 노출하지 않으며, 자금으로 재구입할 수 있다. 기존 데이터의 확장 필드와 차량 식별자·운행 기록을 보존한다.
- 운영 화면의 추가 설명은 줄이고 판매/구매 상태와 주요 금액만 간결하게 표시한다.
- 정식 DB `myon-taxi-v007 / game / main` 유지. 해당 DB가 비어 있을 때만 과거 `myon-taxi-v006`에서 자료를 읽어 복사한다. 미리보기 전용 시나리오 및 테스트 버튼은 정식 코드에 포함하지 않았다.

## 검증
- 인라인 JavaScript 구문 검사 통과.
- 격리된 동작 검사: 50대 추가 구입 차단, 51대 기존 데이터 보존, 미상환 차량 판매 불가, 완납 차량 판매 15,000,000 M 지급, 49대 재구매, 최종 1대 판매 후 첫차 중복 지급 방지, 새 사용자 최초 1회 지원.
- 실제 GitHub Pages 반영과 각 사용자 브라우저 데이터 적용은 배포 후 확인이 필요하다.

## 후속 작업
- 화물·택배 등 다른 차량 분야 도입 시 **전체 차량 한도 50대 공유** 연결.
- 별도 회사/연구/연구팩 기능은 현재 도입하지 않는다. 이전 경로 `?mode=taxi`, `?mode=missions`, `?mode=legacy` 유지.
