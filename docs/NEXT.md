# MYON 다음 작업 인계

> 기준일: 2026-10-24
> 기능 버전: **v0.07.01**
> 상태: **새 홈·운영·설정 / 메신저 1회 알림 / 택시 데이터 승계 반영**

## v0.07.01 구현
- 기본 진입 `public/myon.html`: 게임은 홈에서 시작하고 하단 탭은 홈 / 운영 / 설정.
- 첫 메시지는 운영 탭 알림으로 한 번 표시, 운영 → 메신저에서 언제든 대화 다시 보기.
- 유저는 '도와드릴게요.' 버튼으로 즉시 답변 전송. 지원팀 입력 중 연출 후 '감사합니다. 선택가능한 분야를 선택해주세요.' 안내.
- 신규 플레이어의 택시 선택 → 첫차 지원받기(90% 시 지원) → 택시 운행 → 홈 운영 현황 미터기.
- 현재 첫 사업 택시만 구현. 사업을 선택한 뒤 다른 분야 목록은 숨긴다.
- 택시 미터기에는 남은 거리·남은 시간·실시간 요금·진행 바만 표시. 지원금 상환 UI는 새 화면에서 제거.
- 기존 v0.07 택시 IndexedDB 그대로 사용해 잔고, 차량, 지원금, 운행 시간/진행률, 운행 횟수 유지. 없으면 v0.06 데이터를 읽어 복사하여 승계(이전 DB는 읽기 전용).
- 기존 차량 보유자는 최초 지원 차량을 다시 받을 수 없으며 홈 운영 현황에 보유 차량이 나타난다.
- v0.06.03 배포 커밋별 HTML 캐시 갱신, 이전 임무판/레거시/택시 화면 경로 보존.

## 검증
- 신규 사용자의 1회 메시지 / 입력 중 연출 / 분야 선택 / 첫차 지급 / 재접속 상태 유지 로직 확인.
- 기존 v0.07 기록이 있을 때 그 값을 우선 사용, v0.07이 없을 때 v0.06 데이터를 승계하고 기존 데이터는 불변으로 유지하는 로직 확인.
- HTML 내 자바스크립트 구문 검사 완료.
- 실제 모바일 브라우저 또는 GitHub Pages 배포 반영 여부는 별도로 검증해야 함.
