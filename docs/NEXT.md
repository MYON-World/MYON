# MYON 다음 작업 인계
> 기준: 2026-10-27 / v0.08.14

## 적용 범위
- **자금/요금/보상 시스템 미포함**. 현재 사용자가 자금 적용을 보류했고 **신규 업그레이드 2개만** 구현.
- `자동 임무 수락 2단계`: 1단계 해금 후 무작위 등장, 24시간 수동 연구. 완료 시 10분 자동수락 간격·1분 쿨타임 제거. 일반 임무만 폐기 임박순으로 여유 진행 슬롯에 즉시 연속 자동수락. 새 정상 임무 등장 직후에도 수락.
- `임무 수량 증가 2단계`: 첫 접속부터 무작위 등장, 2시간 수동 연구. 완료 시 전체 카드 상한 **10→20**. **동시 진행 최대 10개는 유지**.
- 두 연구 모두 `[도시]` 접두어를 사용하는 기존 미수락/진행 카드로 등장. 자동수락 금지. 미수락 폐기 시 재등장 가능, 완료 후 영구 해금 및 등장 중단.
- 이전 1단계 자동 수락만 완료한 계정은 기존 10분에 1회, 첫 수락 전·수락 후 1분 쿨타임 유지.

## 기존 게임/화면/저장 호환성
- 기존 도시32종+교통30종 총 일반 임무62종 및 연구 10단계의 시간표, 단계별 등장·폐기시간과 미수락/진행 정렬을 유지.
- 분야 선택 상단 태그 없음. 각 카드 `[도시]` 등만 표시. 0.08.05 상단 시계, 기본 한 줄 카드 CSS, 하단 4개 메뉴 변경 없음.
- IndexedDB `myon-v00804-progress/game/v00806-main` schema 3 유지. 기존 `timeLevel`, `autoUnlocked`, `nextAutoAt`, `cooldownUntil`, `timingVersion`, 기존 개별 임무 `expiresAt`/`finishesAt` 그대로.
- 저장에 두 선택 필드 `autoInstantUnlocked`, `capacityUnlocked` 추가(기존 세이브 누락 시 false). 오프라인 완료된 신규 연구는 복귀 시 바로 영구 적용.
- 자동수락 2단계에서도 임무를 신규로 무제한 생성하지 않고, 표시된 유효 일반 임무만 자동 수락. 오프라인 동안 수락 작업 반복 소급 없음.

## 검증
- 모의 DOM·IndexedDB **47개 동작 검사 모두 통과**: 연구 등장 조건/24h/2h, 단계별 자동수락, 1단계 쿨타임, 10→20 카드, 동시 진행 10, 연구 수동 전용, 오프라인 연구 완료, 영구 저장, 0.08.13 이전 저장 복원.
- GitHub Actions 빌드 및 GitHub Pages 배포 성공을 커밋 후 각각 확인한다. 실제 모바일 장시간 플레이 검증은 별도 수행 필요.
