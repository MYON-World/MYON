# MYON 다음 작업 인계
> 기준: 2026-10-25 / v0.08.04

## 기준 초기화 (이번 커밋)
- **사용자 지시로 v0.08.03까지의 진행 데이터를 초기화한다.** v0.08.04는 저장 DB를 `myon-v00804-progress`로 바꾸고 기존 `myon-v008-progress`의 게임 진행은 가져오지 않는다.
- 이전 v0.08 진행 DB는 새 DB에 1회 초기화 표식(`v00804-initialized`)을 남기는 방식으로 삭제 시도. 이전 버전 탭이 삭제를 막더라도 별도 DB이므로 기존 연구/임무가 새 화면에 복원되지 않는다.
- 첫 방문 시 기본 임무 3개만 생성하며 시계·저장·시간 연구는 미해금. 임시 저장 연구 및 시간 연구는 **각각 랜덤 등장**, 사용자가 직접 '시작'을 눌러야 연구 시작.
- **v0.08.04에서 새로 얻은 연구 기록은 재접속 시 보존**한다. 이 버전부터 새로고침마다 재초기화하지 않는다.
- v0.07 및 별도 구버전 DB에는 접근하지 않는다.

## 계속 유지할 시스템
- 임시 저장 연구: 게임 실행 누적 1시간. 시작 시 해당 연구의 상태만 IndexedDB에 먼저 기록. 완료 후 전체 임무·연구·해금 자동저장.
- 시간 연구: 게임 실행 누적 24시간. 완료 후 KST `yyyy.mm.dd HH:MM` 시계와 한 줄 카드 폐기/완료 카운터 표시.
- 일반 임무와 두 연구 합계 동시 진행 10건으로 제한(표시 없이 11번째는 시작 불가).
- **오프라인 진행 없음.** 브라우저 종료·숨김 중에는 임무·연구·폐기/등장 대기가 정지하고 재접속 시 남은 시간부터 재개한다.
- 홈/회사·설정 잠김, 무작위 임무 등장, 스크롤바 숨김, 상태 메시지 간소화 유지.
- 저장자료 내보내기/불러오기, 오프라인 진행 해금은 추후 설정 메뉴 연구 대상으로 남김.

## 검증 및 다음
- JS 문법 검증, 옛 진행 DB 존재 상태에서 신규 시작/기존 DB 삭제 및 1회 표식, 재실행 중복 삭제 방지, 새 연구 직접 시작/저장/복원, 12시간 종료 후 남은 시간 유지, 1시간 완료 뒤 전체 저장을 모의 브라우저에서 검증.
- 실제 모바일·브라우저의 강제 종료/브라우저 저장 제한 동작은 실기기 추가 확인 필요.
- 새 기능/업그레이드/커밋은 관리자 명시적 지시 전 추가하지 않는다.
