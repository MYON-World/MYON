# MYON 다음 작업 인계
> 기준: 2026-10-28 / v0.09.01

## 실제 적용 사항
- 기존 게임의 일반 무작위 임무에서 택시 태그 5종 제외(62→57). 기존 저장의 택시 임무는 이름/시각을 `retiredTaxiMissions`로 기록 보존. 나머지 도시 32종·기타 분야 25종·연구 및 자동수락 그대로.
- 운영 메뉴 최상단 **공용자금 M** 표시, 초기 0 M. 기존 7종 전폭 메뉴 그대로(택시 활성, 나머지 6개 잠금).
- 택시 화면은 레벨/EXP/24h 레벨 해금, 차량 확보(24h 1대)/판매(자부담 50%), 기본요금/심야운행/시 지원 축소/차량가격 4개 스킬 현황.
- 차량은 시 지원 최초 100%로 무료 확보, 택시 실차 기준가격 25.950 M, 차량가격 단계1(10%) 기준 2.595 M. 총합 최대30대. 판매해도 다시 확보까지 24h 쿨타임 유지.
- 보유 택시는 운영 종합판에 2행 2열 차량 카드, 위(차량명/남은시간) 아래(남은 km/자부담 운행수익) 표시.
- 3~10 km 무작위 자동운행. 택시 완료마다 EXP +1 및 **분야 추가 보상 Lv.1 300 M, 매 레벨 +300 M**을 공용자금에 지급. 카드의 차량 운행 수익은 이 보상과 분리; 시 지원 100%면 0 M.
- 분야 레벨은 무한, EXP 300마다 수동 시작 24시간 해금을 거쳐 레벨+1. 기본요금은 Lv.1 1,000원, 레벨별 +1,000원, 5,000원 상한.
- 기존 DB `myon-v00804-progress`, 기존 임무키 `game/v00806-main` schema3 유지. 택시 데이터는 독립 키 `game/v00901-taxi` schema1에 저장. 재접속/오프라인 정산 지원(진행 중인 운행 1회만).

## 임시 계산 가정 — 사용자 승인된 최종 밸런스 아님
- 시가지 평균속도 30 km/h로 운행 타이머 계산 (3~10km에 6~20분).
- 서울 택시 기본거리 1.6km, 131m 추가요금을 MYON 기본요금/실제기본요금(4800원)에 비례 축소하여 요금 산정. 운행자 수익은 요금 M 환산 × 자부담 비율.
- 심야 해금 전 04:00~22:00 KST에만 신규 운행 시작. 22:00을 넘긴 기존 진행은 완료 후 새 운행 대기.
- 1M은 100만 원 단위로 계산. 공용자금 및 운행 수익은 같은 단위를 사용.

## 미정 — 임의 구현 금지
- 4종 스킬의 학습 비용과 구체 해금레벨/조건, 심야운행 실제 해금 후 할증률, 확정된 속도 및 요금 축소비율.
- 다른 운송 분야의 운영·레벨·보상, 미래 차량 카드/합산한도 연결, NPC 운행 규칙.
- 페이지 상단 MYON/KST 시계·하단 4메뉴·기존 임무 스키마 변경 금지.
