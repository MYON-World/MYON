# MYON 다음 작업 인계
> 기준: 2026-10-25 / v0.08.02

## 이번 업데이트
- 무작위 등장하는 `시간 연구` 카드 추가. 연구 24시간(실제 경과시간) 동안은 `연구 진행중`만 표시.
- 미수락 시간 연구가 폐기되면 8~25초 후 다시 무작위 등장. 미수락 연구 유효기간은 일반 임무와 동일(17~33초).
- 연구 완료 후 상단 오른쪽에 `yyyy.mm.dd HH:MM` KST 디지털 시계. 1초=1틱.
- 연구 이전에 시계와 남은 시간은 모두 비노출. 연구 완료 후 기존 임무까지 한 줄로 전환: `임무명 / 폐기 MM:SS / 시작` 또는 `임무명 / HH:MM:SS`.
- 기존 일반 임무 10건 숨김 제한, 시작 버튼, 우연 등장·자연 폐기·숨겨진 완료시점, 회사·설정 잠금, 숨긴 스크롤바 유지.
- 연구는 일반 임무 진행 건수 제한에 포함되지 않는다.
- **자동/수동 저장 기능 없음:** 새로고침/브라우저 닫기 시 연구 진행·해금 상태까지 초기화. 이는 차후 저장 업그레이드 설계가 필요한 현재 제약.

## 앞으로 결정할 것
- 회사, 설정, 자금, 자동화, 저장 해금 및 도시 경제·성장 시스템은 아직 미정.
- 임무 등장 4~8.5초 / 미수락 폐기 17~33초 / 완료 2~6분은 이전 내부 임시 밸런스 그대로 유지.
- 새 기능 추가 시 이전 업그레이드 및 UI 규칙을 유지, 명시적 승인 전 커밋 금지.
