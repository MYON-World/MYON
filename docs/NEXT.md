# MYON 다음 작업 인계

> 기준: 2026-10-26 / v0.08.08

## v0.08.08 임무시간 체계
- 사용자 확정: 일반 임무 32종은 임무별 **현실 작업시간 잠정 추정치의 10%**(90% 단축)를 소요한다. 작업 규모에 따라 현실 작업시간은 달라지므로 이 표는 실측 평균이 아닌 **게임 밸런스용 가정**이다.
- 현실 1시간 → 게임 6분: 생활 물자 운송, 긴급 물자 확보, 지역 의료 물품 확보, 지역 식료품 확보, 복지시설 물품 공급, 공공 급식 공급.
- 현실 2시간 → 게임 12분: 공공시설 점검, 도로 안전 점검, 통신 시설 점검, 정수시설 점검, 주거지역 전기 점검, 상업시설 안전 점검.
- 현실 4시간 → 게임 24분: 지역 전력 공급, 상가 물품 공급, 생활용수 확보, 공장 자재 운송, 가로등 정비, 정류장 시설 보수.
- 현실 6시간 → 게임 36분: 지역 환경 정비, 배수시설 정비, 물류 창고 정비, 공원 시설 정비, 폐기물 처리 지원, 지역 통신망 보수.
- 현실 8시간 → 게임 48분: 노후 시설 보수, 산업 설비 정비, 주거시설 보수, 산업단지 설비 보수, 학교 시설 보수.
- 현실 12시간 → 게임 72분: 노후 배관 교체, 하천 시설 복구, 산업 폐수 정비.
- **자동 임무 수락 해금 임무 24시간은 제외**하고 변경하지 않는다. 자동 수락 주기 10분·쿨타임 1분·전체 카드 10개 상한도 그대로.
- **이미 시작한 임무**의 완료예정시각(finishesAt)은 기존 저장값을 유지한다. v0.08.08 이후 수동·자동으로 새로 수락한 일반 임무부터 새 시간표를 적용한다.
- 임무 등장 간격 4~8.5초, 미수락 폐기 17~33초, 오프라인 진행, 저장 DB `myon-v00804-progress`의 `game/v00806-main` (schema 3), 기존 해금 상태 유지.
- **v0.08.05 레이아웃 고정**: HTML·CSS·카드·시계·하단 메뉴는 손대지 않고 버전 제목과 엔진 캐시 키만 갱신한다.

## v0.08.07 긴급 레이아웃 수정
- 사용자 지정: **0.08.05 레이아웃 + 0.08.06 기능**. 새 HTML은 0.08.05 원본에서 버전 문자열만 바꾸며 CSS/시계/카드/메뉴를 모두 유지.
- 0.08.06 `sortCards()`가 DOM 전체를 재삽입하던 `list.append(...nodes)`를 제거하고 시각적인 CSS `style.order`만 적용. 카드를 재생성하거나 사용자 스크롤을 초기화하지 않는다.
- 데이터 레코드 `v00806-main`(schema 3)을 그대로 사용하여 진행 임무와 자동수락 해금·쿨타임을 보존한다. 기존 키 삭제나 초기화 없음.
- 모의 브라우저/IndexedDB 25개 항목 검사 통과: 정렬 후 DOM·스크롤 불변, 자동수락 우선순위, 10분 제한, 10개 한도, 오프라인 해금, 기존 저장 이관.
- 모바일 브라우저 실기기 레이아웃과 스크롤 동작은 아직 별도 확인 필요.

## v0.08.06 적용 사항
- 기존 v0.08.05의 대형 KST 디지털 시계, IndexedDB 자동저장, 오프라인 경과시간, 4개 메뉴를 모두 유지.
- **자동 임무 수락 해금 카드** 추가: 다른 임무처럼 무작위로 등장·폐기, 직접 시작 후 **24시간** 경과하면 기능 영구 해금.
- 자동 수락: 첫 해금 시 **1분 쿨타임**, 이후 일반 임무를 **최대 10분에 1건** 자동 수락하며 추가 **1분 쿨타임** 기록. 대상 중 **가장 먼저 폐기될 일반 임무** 우선. 대상 없음·진행 한도 시 미수락 상태 유지.
- **정렬**: 미수락 임무를 위로(폐기시간 빠른 순), 수락 임무는 아래로(완료시간 빠른 순). 해금 임무에도 같은 정렬.
- **전체 카드 총 10개 제한**: 미수락·수락·해금 임무 통합. 10개일 땐 추가 무작위 생성 없음, 9개 이하가 되면 등장 가능. 기존 동시 진행 10개 제한도 유지.
- v0.08.06 당시 일반 임무는 2~6분. v0.08.08에서 일반 임무만 6~72분으로 변경. 미수락 폐기 17~33초, 등장 간격 4~8.5초 유지.
- 오프라인 동안 이미 존재하던 해금 임무 완료를 처리하고 자동 수락 상태를 보존. 미접속 중 임무를 계속 만들어 대량 소급 수락하지 않음.
