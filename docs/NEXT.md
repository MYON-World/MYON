# MYON 다음 작업 인계
> 기준: 2026-10-25 / v0.08.03

## 이번 구현
- `임시 저장 연구`는 일반 임무와 별도로 무작위 등장. 미수락 상태에서 폐기되면 무작위 시간 뒤 다시 나타난다(현재 8~25초 임시 밸런스).
- 연구 시작 시 **그 연구의 시작·종료 시각만** 새 IndexedDB `myon-v008-progress`에 즉시 저장한다. 이 단계에서 브라우저를 닫아도 저장 연구 1시간은 이어진다. 다른 임무/시간 연구는 아직 저장되지 않는다.
- 1시간 후에는 전체 임무, 시간 연구, 시계 해금 상태와 절대 시각/스폰 타이밍을 IndexedDB에 자동 저장. 브라우저를 나갔다 와도 기존 진행을 복원한다.
- 기존 시간 연구(24시간), 진행 전 폐기 시간 및 진행 중 남은 시간은 시계 해금 후 한 줄로 표시. 미해금 상태에서는 모두 숨긴다.
- 스크롤바 숨김, 개별 임무 카드, 홈/회사/설정 잠금, 일반 임무 최대 10건은 그대로 유지.
- 내보내기·불러오기는 아직 미구현. 설정 메뉴가 해금되었을 때만 제공한다.

## 기술
- 엔진: `public/myon-engine.js` (버전 붙은 URL로 캐시 구분), UI: `public/myon.html`, 앱 호스트: `src/App.vue`.
- 연구 기록/전체 상태: `myon-v008-progress` IndexedDB `game/main`. 기존 `myon-taxi-v007` 저장 데이터에 접근하지 않는다.
- 1초마다 화면 갱신, 시간은 `Date.now()` 기준 실제 경과시간. 저장은 상태가 바뀔 때와 페이지 이탈 시 호출.
- 시간 연구 24시간 진행 중 저장 연구가 완료됐다면 현재 시간 연구도 전체 스냅샷으로 저장된다.
