# MYON 다음 작업 인계
> 기준: 2026-10-27 / v0.08.12

## v0.08.12 기능
- 도시 32종 + 신규 교통 30종(택시/버스/철도/항공/선박/우주 각 5종) = 일반 임무 총 62종. 30개 교통 임무의 이름, 현실/10% 시간표는 `docs/MISSIONS.md` 참조.
- **전체·도시·택시·버스·철도·항공·선박·우주** 8개 분야 태그를 상단 시계와 기존 임무 목록 사이에 추가. 카드에는 `[도시]`, `[택시]` 등의 접두어 표시.
- 필터는 DOM 카드의 `hidden`만 변경하고 저장된 임무/진행/폐기/자동 수락/전체 카드 10개 한도에는 관여하지 않음. 다른 태그로 숨긴 임무도 계속 진행.
- 62종 일반 임무 모두 기존 0~10회 시간업그레이드 비율(10%~100%), 등장/폐기 시간표 및 자동수락 기능 공유. 자동수락 해금 및 시간업그레이드 연구는 도시 분야에서 직접 시작만 가능.
- 기존 0.08.05 상단 시계·한 줄 카드 스타일·하단 홈/메뉴 1/메뉴 2/설정 4개를 고정. 승인된 추가 UI는 태그 버튼과 카드명 분야 접두어뿐.
- 이 단계에서 차량 보유·구매·노선 운영·교통 전용 메뉴는 미구현.

## 진행 데이터
- IndexedDB 이름 `myon-v00804-progress`, 저장소 `game`, 레코드 키 `v00806-main` schema 3, `timingVersion:1` 그대로.
- 기존 도시 임무의 이름·만료/완료 예정시각, 자동수락 해금/쿨타임, 10회 연구 단계와 오프라인 경과 처리는 변경 없음.
- 태그 선택은 화면만 필터링하며 별도 저장하지 않음. 재접속 시 전체가 기본 선택.

## 검증 및 후속
- 모의 DOM·IndexedDB 기능 50항목 통과: 8개 태그, 62종 명칭 중복 방지, 분야별 5종, 기존 저장 복원, 태그 필터 전환/수동수락/연구, 자동수락의 교통 임무 처리, 10%/100% 시간 배율, 10개 카드 제한.
- GitHub Actions 빌드 및 Pages 배포 성공 여부는 커밋 후 별도 확인.
- 실제 스마트폰 화면의 태그 줄바꿈·스크롤·터치와 장시간 오프라인 복귀 QA는 추가 필요.
- 사용자의 명시적 요청 없는 기능·디자인 변경이나 추가 GitHub 커밋 금지.
