# MYON 다음 작업 인계

> 기준일: 2026-10-24
> 현재 버전: **v0.07**
> 상태: **신규 시작 메신저 및 첫 사업 택시 운영 반영**

## v0.07 반영 사항
- 첫 실행 시 화면 전체에 모바일 메신저를 표시한다. 발신자는 임시로 '운영 지원팀'이며, 이용자 답변은 사전 정의된 버튼으로만 선택한다.
- 안내 내용: 도시 교통 운영이 불안정해 도움을 요청하고, 현재는 구현된 첫 사업인 택시를 관리해야 한다고 안내한다. 대화 후 MYON 홈 진입.
- 대화 완료 여부(`introDone`)를 저장하여 재접속 시 반복하지 않는다.
- v0.07은 이전 게임 진행 데이터와 분리해 초기 자금 **0 M**, 택시 **1대**로 새로 시작한다. 저장 DB **myon-taxi-v007 / game / main**.
- 과거 **myon-taxi-v006** DB 자체는 삭제하지 않는다. v0.06 이전 버전 접근 경로 및 자료를 보존한다.
- 홈에 현재 택시 관찰 목표와 초기 동시 관찰 한도 **1대**를 표시한다. 기존 택시 자동운행/실시간 미터기/시 지원금 상환은 변경 없이 유지한다.
- v0.06.03의 빌드 ID 쿼리를 통한 정적 화면 캐시 구분 기능을 유지한다.

## 기존 구현 중 유지
- 최초 택시 1대 자동운행, 택시 최대 20대(새 보유 한도는 아직 결정되지 않아 이전 동작 유지).
- 거리·시간·실시간 요금·시 지원금·상환·재접속 자동 정산.
- 택시 요금 및 시 지원금 계산 로직 변경 없음.
- `?mode=missions`, `?mode=legacy` 및 GitHub Pages 배포 경로 유지.

## 다음 설계 / 아직 미구현
- 회사 영구 성장, 연구팩 아이템 및 연구 시스템, 분야별 성장/완성 조건.
- 적은 차량으로 사업을 성장시키는 신규 구조와 관찰 슬롯 확장 규칙(초기 1대만 확정).
- 화물·택배 및 향후 선택 가능 분야. **현재 게임에서 첫 사업은 택시만 선택 가능**.
- 철도/항공의 실제 데이터 기반 관찰 시스템, 복합열차·폐색 등은 이후 별도 설계.
- v0.07의 홈 레이아웃·문구·목표 체계의 후속 개선은 관리자 승인 후 구현.
