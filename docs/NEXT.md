# MYON 다음 작업 인계

> 기준일: 2026-10-24
> 기능 버전: **v0.07.02**
> 상태: **메시지 제거 / 회사 도입 보류 / 운영에서 택시 차량 지원 / 홈·운영 미터기**

## v0.07.02 구현
- 기본 진입 `public/myon.html`. 하단 탭은 홈 / 운영 / 설정.
- 메시지 및 메신저, 알림과 대화 시작 절차를 제거하고 회사 화면은 보류.
- 신규 사용자는 운영에서 **택시 차량 지원받기**를 눌러 시 지원 90%의 첫차를 1회 받는다.
- 택시를 보유하면 홈의 운영 현황과 운영 탭 모두에서 **남은 거리·시간·현재 요금·진행바**를 표시한다.
- 기존 차량, 자금, 운행 시각/진행률, 운행 횟수, 지원금 잔액/지원율은 `myon-taxi-v007 / game / main`에 유지하며 새로 초기화하지 않는다.
- v0.07 데이터가 없으면 v0.06 DB에서 복사하여 승계한다. 이전 DB와 과거 택시/임무판/레거시 경로, 배포별 캐시 갱신은 유지한다.
- 구버전 메시지 필드는 화면에서 사용하지 않지만 기존 확장 필드를 임의로 지우지 않는다.

## 검증
- HTML 내 자바스크립트 문법 검사 통과.
- 독립 브라우저 테스트: 신규 첫차 지원 → 운영·홈 미터기 표시 확인.
- 독립 브라우저 테스트: 기존 v0.07 진행 데이터 승계 및 중복 지급 방지 확인.
- 독립 브라우저 테스트: v0.06 데이터만 있는 경우 복사 승계 및 이전 DB 불변 확인.
- 실제 GitHub Pages 배포 완료와 사용자의 브라우저 데이터 적용 여부는 별도 확인이 필요하다.

## 보류 과제
- 회사 영역, 시 지원금 직접 상환, 추가 택시 구매, 영구 업그레이드와 연구팩.
- 추가 사업 분야 및 관찰 슬롯 확장 규칙.
- 후속 화면도 실제 게임과 저장 데이터를 계승하는 미리보기로 제시하고 관리자 승인 후 커밋한다.
