# MYON 다음 작업 인계
> 기준: 2026-10-27 / v0.08.11

## v0.08.11 배정 및 미수락 시간 단계별 확장
- 0~10회 시간 연구 진행에 맞춰 새 임무 등장 간격과 미수락 폐기시간 함께 증가. 전체 표는 `docs/MISSIONS.md` 참조.
- 새 임무 등장 간격 = 4~8.5초 × (현재 시간 연구 비율 / 초기 10%). 0단계 4~8.5초 → 10단계 40~85초.
- 폐기시간 = 0단계 17~33초. 1~10단계 상한 1/2/3/5/7/10/14/19/24/30분, 최솟값은 상한의 절반. 10단계 15~30분.
- 일반 도시 임무, 자동 수락 해금(24시간), 시간 업그레이드(5분~24시간 연구)의 모든 새 미수락 카드에 같은 폐기시간 적용. 수락된 뒤 연구/진행시간은 전 버전과 동일.
- 이미 생성된 카드의 `expiresAt`·`finishesAt` 수정하지 않음. 연구 완료 후 새로운 카드에만 단계별 만료시간 적용.
- 연구 완료 시 다음 임무 등장시각은 새 단계로 재예약. 0.08.10 이전 저장과 오프라인 연구 완료 후 복귀한 기록도 다음 등장시각만 새 단계에 맞춰 1회 재예약.
- IndexedDB `myon-v00804-progress/game/v00806-main` schema 3 유지. `timingVersion:1` 추가. 이전 임무/레벨/자동수락 잠금 및 쿨타임 이어받기.
- 새 연구 카드는 자동수락 금지, 일반 임무만 10분에 1건 자동수락/1분 쿨타임 유지. 전체 카드·진행 슬롯 10개 제한 및 정렬 규칙 유지.
- **0.08.05 원본 레이아웃 HTML/CSS 완전 고정**, `public/myon.html`은 버전 문자열 외 변경 금지.
