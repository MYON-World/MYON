- 내 정보에는 기존 플레이어 프로필 및 플레이 스타일 선택, 관람형 전체 8~30건·분야별 수량/임무 초기화 설정을 보존한다. 비서 세부화면에는 분석 통계·버전 변경기록 드롭다운을, 임무판 세부화면에는 `개발중` 임무판/다음 임무 등장 시간/가능한 임무 카탈로그를 보존한다.
- 비서 24시간 분석 완료 후 `비서`라는 이름과 통계, 버전 변경기록만 보여준다. `임무 분석 지속중`, `상시 분석`, `개선중` 태그와 중복 줄은 숨긴다. 최초 24시간의 `개발중` 태그·분석 상태·카운트다운/진행률은 그대로 보존한다.
- 관여형 상세 설정인 `차량 없이 임무 수행` 및 `보유 차량으로 임무 수행`의 라디오 및 저장 UI/로직 제거. 저장된 v0.13.19 설정의 불필요한 `involvement` 필드는 무시하면서 `style`, `total`, `counts` 정보와 기존 모든 자료를 보존한다.
- 관여형 **미래 설계 기준**: 목표 동시 임무 총 100건. 차량을 보유하지 않으면 무차량 임무 100건; 차량을 보유하면 최대 50대의 차량 수량만큼 차량 임무, 남은 수량은 무차량 임무. 예: 10대→차량 10건+무차량 90건. 현재 보유 차량 수를 나타내는 자산 데이터와 재정/임무별 콘텐츠 및 수락 방법은 확정되지 않아 아직 이 100건 임무를 **실제로 생성하지 않는다**.
- 혼합형 **미래 설계 기준**: 관람형처럼 자동으로 임무를 공급·진행하되 관여형에서 개선된 임무 종류를 사용한다. 개선된 임무가 아직 정해지지 않았기에 이번 버전에서는 기존 자동 관람 엔진을 유지한다. 별도의 혼합형 상세 설정은 추가하지 않는다.
- 기존 데이터베이스 `myon-v00804-progress`, 스토어 `game`, 임무 `v01302-world`, 비서 `v01313-assistant`, 연구/메뉴, 프로필 `v01319-player-profile`, 플레이 스타일 `v01319-play-style` 키 및 저장 스키마는 유지한다. 재정·차량 메뉴, 구매 또는 신규 임무 생성 규칙을 임의로 추가하지 않는다.

# MYON 관전 분석 자동 비서전환 — v0.13.18 (2026-11-12)

- 분석 시작부터 관전임무 분석 카드는 **항상 임무 목록 최상단 고정**. 현실시간 24시간 경과 및 분석 진행률·통계는 유지.

- 최초 24시간 분석 중: '관전임무 분석중'+'개발중', 이후: '비서'+'개선중'. 개선중은 수동으로 완료 판단 후 추후 버전에서 제거할 임시 태그.
- 기존 변경기록/설정 및 하단메뉴 **새 연구 제안은 일시 중단**. 진행 중이던 이미 수락된 연구는 원래 완료 시각에 해금을 적용하되 추가 제안 없이 정지. 이전 연구/해금/설정 데이터 유지. 해금된 홈·캐릭터/변경사항 알림/설정 기능도 보존.
- 기존 23종 관전 임무, 정각 배정, 진행 중 운행, 저장 및 오프라인 계산 모두 불변. 연구 단계 DB 스키마 변경하지 않음.

- `main` 정식 게임 한 가지를 기준으로 운영한다. 다른 환경의 공개 사이트와 환경 전환 메뉴는 제거한다.
- 기존 v0.13.09 임무 시스템을 v0.13.10에서도 유지한다: 시간당 신규 임무 1회 시도, 동시 최대 30개, 임무별 진행·종료.
- 기존 정식 저장은 `myon-v00804-progress` 데이터베이스, `game` 스토어, `v01302-world` 키를 그대로 사용한다. 과거 데이터/스키마를 삭제하거나 초기화하지 않는다.
- 사용자가 오프라인이었던 시간에도 임무 생성·진행·완료를 소급 계산한다.
- 좌측 상단 톱니 아이콘만 유지하며 연결된 설정 기능은 아직 없다.
- GitHub Pages는 `main` 브랜치의 `dist/`만 배포한다.
