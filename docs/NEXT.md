# MYON 다음 작업 인계

> 기준: 2026-10-26 / v0.08.05

## 이번 커밋
- v0.08.04에서 v0.08.05로 전환. 기본 게임 화면은 `public/myon.html`, 실제 로직은 `public/myon-engine.js`.
- 디지털 시계를 **처음부터** 상단 오른쪽에 노출: 위에 작은 KST `yyyy.mm.dd`, 아래에는 크게 `HH:MM`, 1초=1틱.
- `시간 연구`·`임시 저장 연구` 제거. 처음부터 IndexedDB 자동저장·오프라인 시간 계산 활성화.
- 미수락 카드 `폐기 MM:SS`, 진행 카드 `HH:MM:SS` 한 줄 표시, 기존 임무 지속시간 유지.
- 기존 하단 3개 메뉴에서 **홈 / 메뉴 1 / 메뉴 2 / 설정** 4개로 변경. 홈만 사용 가능.
- 무작위 등장·시작/종료·동시 10건·스크롤바 숨김·기존 스타일 유지.

## 저장 이관
- 과거 v0.08.04 저장 DB `myon-v00804-progress`를 재사용. 단, 이전 `game/main`은 보존하고 새 `game/v00805-main`을 사용.
- 새 저장이 없을 때에만 기존 `schema 1/kind full`에서 일반 임무와 마감시각을 마이그레이션.
- 과거 연구 기록만 존재하면 그 버전에는 임무 저장이 없었으므로 신규 임무 3개 생성(자료를 임의 삭제하지 않음).
- 종료 중 실제 시간 경과로 완료/폐기된 임무는 복원하지 않음. 미접속 동안 임무를 계속 생성해 누적하지 않으며 접속 시 최대 한 건 등장.
- 저장은 상태 변경마다, 주기적으로, 페이지 비활성/이탈 시 시도. 새 키가 생긴 이후 v0.08.04 자료로 덮어쓰지 않음.
