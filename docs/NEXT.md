# MYON 관전 분석 자동 비서전환 — v0.13.18 (2026-11-12)

- 오프라인 복귀 시 기존 게임의 정식 소급 계산을 먼저 완료한 다음, 비서 누적 분석 수치를 복원한다.
- 비서는 지금은 읽기 전용 관전자이며 임무, 자금, 배차, 시간 속도를 변경하지 않는다.
