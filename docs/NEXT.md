# MYON 다음 작업 인계

> 기준일: 2026-10-24
> 기능 버전: **v0.07.03**
> 상태: **운영에 차량 구입·시 지원 상환 추가 / 기존 택시 자료 승계**

## v0.07.03 구현
- 기본 진입 `src/App.vue` → `public/myon.html`; 하단 홈 / 운영 / 설정 3개 탭은 유지.
- 기존 v0.07.02의 메신저 제거·회사 메뉴 보류, 신규 사용자 1회 첫차 지원, 홈·운영 실시간 초간결 미터기를 유지.
- 운영에 **차량 구입** 메뉴 추가: 첫 차량 보유 후 시 지원율 0~90% 설정, 차량가격 30,000,000 M 기준 지원금·자기 부담금 계산, 최대 20대 구매 제한. 자기 부담금 지불 후 새 택시 즉시 운행.
- 운영에 **시 지원 상환** 메뉴 추가: 차량별 남은 지원금 및 지원율 확인, 부분·전액 상환, 자금 및 지원금 잔액 동시 반영. 운행 수익에서 지원금 자동 공제는 유지.
- **기존 `myon-taxi-v007 / game / main`을 그대로 사용**해 자금, 보유 차량, 운행 진행 상태, 지원금 잔액과 기존 확장 필드를 유지한다. v0.07 기록이 없을 때만 v0.06 자료를 읽어 복사하고 구버전 DB는 수정하지 않는다.
- 이전 택시·임무판·레거시 화면 경로와 배포별 빌드 캐시 갱신을 유지한다.

## 검증
- 인라인 JavaScript 구문 검사 통과.
- 격리 브라우저의 가상 IndexedDB 검사: 첫차 지원, 운영·홈 미터기, 기존 차량 보유 시 중복 지원 방지, 지원율 변경에 따른 자기 부담금 계산, 추가 차량 구매 및 운행 시작, 부분·전액 상환, 저장 데이터 확장 필드 유지 확인.
- 브라우저 환경에서 로컬 HTTP 테스트 서버 접근이 차단되어 가상 IndexedDB 기반 화면 테스트를 사용했다.
- 실제 GitHub Pages 배포 및 사용자별 실제 저장 데이터 적용은 배포 이후 별도 확인이 필요하다.
