# MYON 전체 임무 목록 · 임무시간 연구
> 기준: 2026-10-27 / v0.08.14
> 현실시간은 실측 산업 평균이 아닌 게임 밸런스용 잠정 추정치다.

## 기본 규칙
- 일반 임무는 현실 추정 작업시간을 100% 기준으로 하며 최초에는 그 10%만 소요한다.
- 10회의 시간 업그레이드를 차례로 마치면 일반 임무의 진행시간이 현실 기준 100%까지 늘어난다.
- 수동 시작과 자동 수락에 같은 시간 비율을 적용한다. 이미 수락된 임무는 기존 완료예정시각을 보존한다.
- 자동 임무 수락 해금 임무의 24시간은 단계별 배율이 적용되지 않는다.

- 연구시간 합계: **57시간 50분**. 마지막 10번째 연구는 **24시간**.
- **1회 완료 후 2회**, **2회 완료 후 3회**와 같은 방식으로 순차 진행한다. 동시에 두 단계가 나타나거나 중간 단계를 건너뛸 수 없다.
- 다음 단계 카드는 홈의 기존 임무 목록에서 무작위로 등장하며, 사용자가 직접 시작해야 한다. 미수락으로 폐기되면 같은 단계가 다시 등장할 수 있다.
- 시간 연구의 진행/완료는 재접속 및 오프라인 경과시간에도 보존된다.
- 업그레이드도 일반 임무·자동 수락 해금 임무와 합쳐 **전체 카드 기본 10개(0.08.14 수량 증가 2단계 후 20개)** 및 **동시 진행 10개** 한도에 포함한다.
- **자동 임무 수락은 일반 임무 32종만 수락한다. 임무시간 업그레이드 1~10 및 자동수락 해금 연구는 모두 자동 수락에서 제외한다. 반드시 이용자가 직접 시작한다.**
- 마지막 10회 완료 후 시간 업그레이드 카드는 등장하지 않으며 일반 임무시간은 100%다.

## v0.08.11 단계별 임무 등장·미수락 폐기시간

| 단계 | 현실시간 비율 | 새 임무 등장 간격 | 미수락 폐기시간 |
|---|---:|---:|---:|
| 초기 | 10% | 4초~8.5초 | 17초~33초 |
| 1회 완료 | 15% | 6초~12.75초 | 30초~1분 |
| 2회 완료 | 20% | 8초~17초 | 1분~2분 |
| 3회 완료 | 30% | 12초~25.5초 | 1분 30초~3분 |
| 4회 완료 | 40% | 16초~34초 | 2분 30초~5분 |
| 5회 완료 | 50% | 20초~42.5초 | 3분 30초~7분 |
| 6회 완료 | 60% | 24초~51초 | 5분~10분 |
| 7회 완료 | 70% | 28초~59.5초 | 7분~14분 |
| 8회 완료 | 80% | 32초~68초 | 9분 30초~19분 |
| 9회 완료 | 90% | 36초~76.5초 | 12분~24분 |
| 10회 완료 | 100% | 40초~85초 | 15분~30분 |

- 임무 등장 간격은 초기 4~8.5초에 연구 비율 배수(10% = ×1, 100% = ×10)를 적용한다.
- 미수락 임무는 별도 단계표에 따라 폐기된다. 초기 17~33초를 유지하고 이후 최소값은 상한의 50%, 최종 15~30분이다.
- 일반 도시 임무, 자동 수락 해금 임무, 시간 업그레이드 연구 임무 **모두 새로 등장할 때** 이 폐기시간을 적용한다.
- 이미 목록에 있는 임무는 완료한 연구와 관계없이 기존 폐기/완료 예정시각을 보존한다.
- 연구 완료 시 다음 무작위 카드 등장 예약은 **현재 시점부터 새로운 연구 단계의 등장 간격**으로 다시 잡는다. 오프라인 연구 완료 후 복귀 시에도 재예약.
- 기존 저장키와 schema 3은 유지. `timingVersion:1` 표시가 없는 오래된 저장은 다음 등장 예약만 새 단계 기준으로 1회 조정한다.

### v0.08.13 통합 목록과 분야 표시
- 상단 분야 선택 태그/필터 없이 **도시·교통 임무 및 연구·해금 임무 모두 한 목록에 항상 표시**한다.
- 카드 이름의 `[도시]`, `[택시]`, `[버스]`, `[철도]`, `[항공]`, `[선박]`, `[우주]` 분야 접두어만 유지한다. 저장된 임무 원본 이름은 변경하지 않는다.
- 미수락은 폐기 임박순으로 위에, 진행 중인 임무는 완료 임박순으로 아래에 표시한다. 같은 기존 CSS `order` 기반 정렬을 유지한다.
- 교통 30종도 동일한 작업시간 연구(10%~100%), 등장/폐기, 자동 수락 규칙을 적용한다. 업그레이드/자동 수락 해금 임무는 수동 시작 전용.
- 모든 분야의 임무를 전체 기본 최대 10개(0.08.14 수량 연구 완료 후 최대 20개)의 카드 제한 안에서 통합 관리한다. 차량 구매·노선 관리나 별도 운행사업은 미구현.

## v0.08.14 신규 연구 업그레이드 2종

| 연구 임무명 | 등장 조건 | 연구시간 | 연구 완료 효과 |
|---|---|---:|---|
| 자동 임무 수락 2단계 | 자동 임무 수락 1단계 해금 완료 | 24시간 | 기존 자동 수락 대기시간·쿨타임 제거. 동시 진행 슬롯에 여유가 생기는 즉시 일반 임무 자동 수락 |
| 임무 수량 증가 2단계 | 최초부터 무작위 등장 | 2시간 | 전체 카드 최대 10개에서 20개로 증가(동시 진행 최대 10개는 유지) |

- 두 연구는 `[도시]` 카드로 무작위 등장하고 **직접 시작**. 자동 수락 불가. 완료한 연구는 재등장하지 않으며 미수락 폐기 시 재등장할 수 있다.
- 새 임무는 카드 전체 한도에 여유가 있을 때만 시간 업그레이드 단계의 기존 간격대로 나타난다. 완료한 연구는 오프라인에서도 해금된다.
- 자동 수락 2단계는 기존 일반 임무 62종만 수락하고, 폐기 예정시간이 가장 가까운 순서대로 비어 있는 진행 슬롯을 채운다. 새 카드도 즉시 자동 수락 가능하다.
- 두 연구 모두 기존 `v00806-main` schema 3에 단계 완료 여부를 추가 저장. 이전 저장자료의 기존 임무/연구 진척 및 절대시각은 그대로 보존한다.
- **이번 버전에는 자금 기능을 넣지 않는다.** 임무별 보상 및 교통요금은 후속 검토 대상이다.

## 유지되는 게임 시스템
- **초기 연구 단계**의 등장 4~8.5초·폐기 17~33초 및 첫 3개 임무는 유지. 연구 완료에 따른 단계별 시간은 위 표를 적용.
- 기존 자동 임무 수락 1단계는 연구 24시간·10분에 1개·1분 쿨타임 유지. 0.08.14 자동 수락 2단계 완료 후에는 쿨타임·대기시간 없이 빈 슬롯에 즉시 수락.
- 카드 정렬은 미수락 먼저/폐기 임박순, 수락 임무는 완료 임박순. 정렬 시 DOM 카드 재삽입 없음.
- 기존 IndexedDB `myon-v00804-progress`의 `game/v00806-main` (schema 3) 유지. `timeLevel` 0~10과 0.08.14 연구 해금 필드 `autoInstantUnlocked`, `capacityUnlocked` 저장.
- 기존 세이브는 레벨 0에서 시작하며 이미 진행 중인 임무와 자동 수락 진행/해금/쿨타임 상태는 유지.
- v0.08.05 HTML/CSS 고정. 새 패널이나 별도의 연구 탭 추가 없음.
